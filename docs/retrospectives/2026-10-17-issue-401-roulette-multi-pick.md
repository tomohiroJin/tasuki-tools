## 踏んだ罠（事実と再発条件）

### 1. 変異の番号が、並行して進んだ #402 とぶつかった

**事実**: PR 1 で「いま使われている最大（282）の次」から 290〜296 を足した。その間に #402 が同じ 290〜296 を main へ入れ、
main を取り込むときに `scripts/lib/mutation-declarations.mjs` が衝突した。#401 の分を 300 番台へ移して直した。

**再発条件**: 2 本以上の枝が、それぞれ「main の最大の次」から番号を取り、どちらも main に入る前に足す。宣言の表の末尾に足す形なので、
衝突は表の行で起きて気づけるが、番号の付け替えにはパッチの名前・1 行目・文書の参照の書き換えが要る。

### 2. 画面の時計が「次の 1 人」しか待たず、時間が一度に進むと止まったままになった

**事実**: 1 人ずつ止まる時刻に描き直すため、最初は「次に来る時刻だけに timer を置き、起きたら次を待ち直す」形にした。
偽の時計で一度に終わりまで進めるテストで、真鍮の席が 1 つのまま増えなかった。

**再発条件**: timer の続きを「描き直しの後の効果」で置き直す形で、timer が予定より遅れて起きる（裏のタブ・重い端末・
テストの一括の進め）。起きた時点で残りの時刻をすでに過ぎているので、待ち直す先が無い。すべての時刻に先に timer を置いて直した（変異 m310）。

### 3. 承認前の札の大きさが、4 人と最長の名前で崩れた

**事実**: モックの初版（組の札の背 10.75rem・名前 `lg`）を 320×640 と 1440×900 で撮って測ったところ、1440 で 4 人の名前が
札からはみ出し、320 で札の下端が「回す」の帯に 17px 掛かった。320 の円盤はすでに最小（14rem）で、円盤からは引けなかった。

**再発条件**: 背を固定した箱に、行の数と流体の字の大きさ（`clamp`）が両方変わる中身を入れる。字の大きさは幅で変わるので、
1 つの幅で見ても足りない。4 人・最長の名前・両端の幅の組で測ってから見せた。

### 4. 文言の書体の検査が、文言の関数を仮の値で呼ぶ

**事実**: 結果の一言の関数を「名前の配列」を受ける形にしたところ、`copy-fits-font-base.test.ts` が落ちた。
この検査は `copy.ts` の関数を `('Ab', 2, 3)` で呼んで文字を集めるので、配列を受ける関数は呼べない。可変長の引数にして直した。

**再発条件**: `copy.ts` に、文字列か数以外を受ける文言の関数を足す。

## 検査の穴（緑のまま壊れていたものは何か・なぜ緑だったか）

- **#94 の変異 m184 が、PR 2 の後は当てても見た目が変わらなくなった**（変異の検査は「未検出」で赤になり、気づけた）。
  真鍮の席・札・一言・一覧を「何人目まで決まったか」1 つで切り替えるようにしたため、元の当て先（舞台の `settled`）は
  円盤の角度にしか効かず、その角度は終わりの時刻で同じ値になる。緑のまま壊れていたものではなく、守る場所が移った。
  円盤の真鍮の席だけが自前の時計で数える形へ当て先を移した
- **E2E はこの作業環境で流せなかった**（Caddy が無い）。2 人・4 人・320×640 の場面は CI の `e2e` に任せた。
  手元の見た目の確かめは、同期フックだけを差し替えて本物の画面を描き、撮って比べる形で代えた（1 人の舞台は前後で画素まで一致）
- `e2e` の単体の 1 件（`PLAYWRIGHT_BROWSERS_PATH` の検査）はこの作業環境では main でも落ちる。環境の設定の差で、この変更とは関係しない
