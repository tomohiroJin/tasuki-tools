## 踏んだ罠（事実と再発条件）

### 1. モックで見えなかった幅の欠陥が、実際の画面の E2E で出た

**事実**: 承認されたモックの CSS を写したところ、1280px で横並びの舞台の列が舞台より 40px 広がり、円盤と札が左右へはみ出した。
`grid-template-columns: var(--wheel-size) …` の `--wheel-size` が `cqi`（コンテナの幅）で書かれていて、
**コンテナである舞台自身のプロパティでは `cqi` が舞台の外の容器を指す**（ここでは画面）ため。子の `.wheel` で使うと舞台の幅で解かれて正しい。
モックは 1440px で撮られ、舞台が広くて出なかった。もう 1 件、脇のパネルは名前が 1 行で切れない（`nowrap`）ので、
既定の列の最小幅（`auto`）が名前の長さで広がり、320px で右へはみ出した。どちらも #316 の「4 つの幅で当たりとはみ出しを見る」検査が捕まえた。

**再発条件**: 承認済みのモックの値を写すとき。モックを撮った幅でしか確かめていない値は、別の幅で崩れる。
**コンテナクエリ単位（`cqi`）をコンテナ自身のプロパティに使わない。**

### 2. 「止まったら札を寄せる」の検査が、先頭にいると空振りした

**事実**: 320×640 で先頭から回すと札が最初から見えており、寄せる処理を丸ごと外しても E2E が緑のままだった（対照実験）。
さらに Playwright の `click()` は押す前にボタンを見える位置へ寄せるため、下までスクロールしてから押しても札が見えてしまう。
下までスクロールし、DOM の `click()` で回す形にして初めて、処理を外すと赤になった。

**再発条件**: 「動かさないと見えない」状況を作らずに、動かしたあとの状態だけを見るとき。壊して赤を見る前に、**壊さずに緑になる条件が、
壊れた実装でも緑になる条件でないか**を見る（検査には対照実行が要る）。

### 3. 検査の射程の外に円盤の文字があった

**事実**: `scanContrast` は SVG の `<text>` を数えない（探索で 0 件）。生の色の検査も TSX の `style` の中は拾わない
（`stopColor: '#ff0000'` でも違反 0 件）。どちらも「緑」が「測っていない」を意味する型。席の名前は専用の測り方
（`expectWheelLabelsReadable`）で、グラデーションの色は CSS のクラスで当てた。**後者の穴は `style` を使う他の画面にも残る**（この PR では塞いでいない）。

**再発条件**: 新しい種類の要素（SVG など）を足すとき。既存の検査が対象に取るかを、アサーションを書く前に 1 回「探索」で見る（計画 3.4 の手順どおり）。

### 4. 回転の終わりを rAF に頼れない

**事実**: ヘッドレスの撮影で 4 秒の回転が 14 秒後まで止まって見えなかった。終わりは残り時間の `setTimeout` で保証し、
rAF は見た目を進めるだけにした。変異 m174 が「timer を外すと、rAF を 1 度も呼ばない環境のテストが赤になる」ことを守る。
動きを減らす設定は CSS の一括の手当ての外（rAF）なので JS が止める（m164）。

## 変異

PR 3 で足したもの: m163（止まる角度が開始角を引かない）・m164（動きを減らしても回す）・m174（終わりを timer で保証しない）・
m175（見えている札も寄せる）・m176（寄せる判定が下端の帯を数えない）。m163 は、開始角 0° だけで試すテストでは殺せない
（どの画面も同じ席で止まるための核）ので、オラクルは**指し針の先を回転子の座標へ戻して `atan2` で席を引く**別の計算にし、
開始角 4 通りで見る。
