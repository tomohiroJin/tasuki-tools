# 受け入れ基準: 一時停止・再開・完成・リセット

> 対象: US4。観測点: タイマー状態の導出（残り時間・稼働経過）、完成記録、フェーズ。

## ストーリー
参加者として、セッションを一時停止/再開し、完成時に記録を残し、必要ならリセットしたい。

## 受け入れ基準

### ルールベース（チェックリスト形式）
- [ ] 経過時間は稼働区間のみ積算し、停止中の時間を含まない。
- [ ] 完成記録は、お題タイトル・言語・難易度・所要時間・メンバー・総交代回数・完成日時を含む。
- [ ] 完成記録は端末ローカルに永続化される（リセットや別セッションで失われない）。

### シナリオ形式（Given-When-Then）

#### AC-1: 一時停止で残り時間が固定される
- **前提** お題が確定したセッションが稼働中である
- **もし** 参加者が一時停止する
- **ならば** 全参加者の残り時間が停止時点で固定される

#### AC-2: 再開で停止時点の残り時間から続く
- **前提** セッションが一時停止している
- **もし** 参加者が再開する
- **ならば** 停止時点の残り時間からカウントダウンが続く

#### AC-3: 所要時間は停止時間を含まない
- **前提** 60秒稼働 → 一時停止30秒 → 再開して40秒稼働している
- **もし** 主催者が完成を確定する
- **ならば** 完成記録の所要時間は100秒である

#### AC-4: 完成で記録が生成される
- **前提** お題が確定したセッションが稼働している
- **もし** 主催者が完成を確定する
- **ならば** 規定のフィールドを含む完成記録が生成される

#### AC-5: 完成は冪等である（人間確定）
- **前提** セッションが完成している
- **もし** 主催者が再度完成を要求する
- **ならば** 完成記録は1件のままである

#### AC-6: 完成後のセッション操作は受理されない（人間確定）
- **前提** セッションが完成している
- **もし** 参加者がセッションの再開を要求する
- **ならば** その操作は受理されない

#### AC-7: リセットで初期状態へ戻る
- **前提** 交代が進んだセッションが進行中である
- **もし** 主催者がリセットする
- **ならば** 現ドライバー・交代回数・お題が初期状態に戻り、設定段階に戻る

#### AC-8: リセットしても完成記録は保持される
- **前提** 過去の完成記録が1件ある
- **もし** 主催者がリセットする
- **ならば** その完成記録は失われない
