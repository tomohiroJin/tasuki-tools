## 依存関係と並列グループ

```
T001 ─┬→ T002 → T003 ─┐
      ├→ T004 → T005 → T006 ─┤
      └→ T007 → T008 ─────────┤
                              ├→ T009 → T010 → T011 → T012
```

- **T001** は全フェーズの前提（現状記録）であり、必ず最初に実行する。
- **T002〜T003（ADR-0009）・T004〜T006（ADR-0002）・T007〜T008（ADR-0001）** は
  互いに別ファイルへの変更であり、T001 完了後は **`[P]` 並列実行が安全**。
  ただし検証コマンドの取り違えを避けるため、実行時はファイル単位に直列で進めてよい。
- **T009〜T012** は3ファイルすべての編集完了後に行う横断検証であり、
  T003・T005（T006 含む）・T008 のすべてが Green になってから着手する。
