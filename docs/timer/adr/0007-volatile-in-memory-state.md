# ADR-0007: 揮発インメモリ状態と再起動安全

- **ステータス**: Accepted
- **関連要件**: FR-012, FR-018, FR-019, FR-020, FR-028, NFR 可用性・プライバシー

## 背景

リアルタイム協調ツールでは、サーバーの状態管理方式が運用性とプライバシーを左右します。永続 DB を
持つと、スキーマ移行・バックアップ・障害復旧の運用が必要になり、個人データ（表示名）の保持責任も
生じます。一方、恒久的な完成記録はチームに残したいニーズもあります。

## 決定

サーバー側のルーム状態は **揮発インメモリ**（`InMemoryRoomStore`）とし、永続化しません。
恒久記録はクライアント側に置きます。

- ルーム・参加者・セッション・タイマーはメモリ上のみ。サーバー再起動で失われてよい（再起動安全）。
- **完成記録は各端末のローカル（IndexedDB）に永続化**し、JSON で入出力できる（FR-028）。
  サーバーが持つ記録は表示用の揮発コピー。
- 参加者は安定 ID（participantId）と接続 ID（connId）を分離し、復帰トークンで再接続後も同一参加者・
  同一役割として扱う（FR-019）。主催者が猶予 30 秒を超えて不在なら最古のオンライン編集者へ自動委譲
  （FR-018）。
- ホストトークン・復帰トークンは `makeHandlers` のクロージャ内 `Map` に保持し、モジュールグローバルを
  避ける（テスト間の状態汚染を防ぐ）。

## 影響

- **利点**: サーバーは秘密も永続データも持たないため運用が単純で、再起動に復旧手順が要らない。
  プライバシー面でも保持する個人データは表示名のみ・揮発。記録は端末に残るため再起動で失われない。
- **代償**: サーバー再起動で進行中セッションは終了する（これは仕様）。トークンや記録は揮発 Map のため、
  資源上限・アイドル回収（M4）が無い現状では長時間運用でメモリが増え得る。これは将来枠で対応する。
- 将来枠: チーム横断の永続記録ストアは M4 以降で検討（その場合は本 ADR を補足する新 ADR を追加）。

## 追記（2026-08-17・#72 E1）

**決定の最後の項目「ホストトークン・復帰トークンは `makeHandlers` のクロージャ内 `Map` に
保持し、モジュールグローバルを避ける」について、保持の実装が移動している。**

3 個の可変 `Map`（`hostTokens` / `resumeTokens` / `roomPassphrases`）は
`apps/timer-sync/src/application/token-store.ts` の `createTokenStore()` へ切り出された。
同ファイル冒頭は「`handlers.ts` の `makeHandlers` が抱えていた 3 個の可変 `Map` …を、
ロジックを変えずに 1 モジュールへ切り出したもの（フェーズ 2・純粋な移動）」と記している。

**ただし決定が名指しした性質は、字義どおりの意味でも今なお満たされている。**
`createTokenStore()` は `apps/timer-sync/src/application/handlers.ts:143` で、
つまり `makeHandlers` の中で呼ばれ、**ハンドラインスタンスごとに 1 個生成される**。
同ファイル 140〜142 行のコメントも「ハンドラインスタンスごとに1個生成し、
モジュール共有を避けてテスト間汚染を防ぐ」と明記している。モジュールグローバルは無い。

変わったのは、`Map` を直接 3 個持つか `TokenStore` オブジェクト経由で持つかという
保持の形だけである。**本追記は、決定の文面が名指しする `Map` が別モジュールの
ファクトリへ移ったことを記録するものであり、決定を覆すものではない**
（`docs/adr/0002` の「ADR は追記のみ」）。

**改定（2026-09-06・#95）**: 役割（`host` / `editor` / `viewer`）とホストの概念を廃止した。
本 ADR 本文の「同一役割として扱う」「主催者が猶予 30 秒を超えて不在なら最古のオンライン
編集者へ自動委譲（FR-018）」は、**役割そのものが無くなったため適用対象を失う**。

復帰トークンによる同一参加者としての再接続は維持する。猶予 30 秒はドライバーの
繰り上げ（R2-1）にのみ残る。

決定の正本は [`docs/adr/0017`](../../adr/0017-bounded-contexts-and-packages.md) と
[設計正本](../../superpowers/specs/2026-09-06-shared-identity-and-rooms-design.md) D5。
