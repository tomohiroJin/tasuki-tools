# 実際の利用シーンと作らないもの

## このガイドの位置づけ

**次に作る機能を選ぶときの物差しである。** 機能を提案する前に読む。
決定そのものは ADR にあり、ここは選ぶときの使い方を示す。新しい義務は作らない
（[`docs/adr/0002`](../adr/0002-document-system-three-layers.md)）。

## 使われている場

Tasuki が実際に使われているのは、次のような**その場で集まって進める作業**である。

| 場 | 使うツール |
|---|---|
| ペア・モブでの作業 | timer |
| お題を決めて、モブで取り組む勉強会 | topic で選び、timer で回す |
| スクラムのリファインメント（見積もり） | poker |
| 朝会の進行役などの順番決め | roulette |
| 会議の進行 | agenda（作ったばかりで、出番はまだ少ない） |

スクラムのふりかえりのように、書いて並べて残す作業は、既存のホワイトボード型の道具に任せる。

## 作らないもの

- **保存は作らない。** Tasuki は揮発インメモリで、保存の機能を持たない。その性質上、作りたくない（憲法 原則 III）
- **キャンバスや、型の多さで競う機能は作らない。** ホワイトボード型の道具と同じ土俵では、機能で負ける。
  ふりかえりの型を増やすほど負ける。ふりかえりのボードを本命にする案は退けた
- 持ち出しが要るときは、保存ではなく**コピー**（Markdown など）で、ほかの道具へ渡す形にする

## Tasuki が勝てる性質

機能は、次の性質のどれかを伸ばすものに絞る。

- その場で使える・全員が同時に見られる
- アカウントが要らない
- 終われば消える
- 同期する
- 時間を区切る
- 順番を回す

## 提案の前に

1. 提案が「使われている場」のどれを深めるかを書く。どれも深めないなら、出さない
2. 保存・キャンバス・型の多さが要る案になっていないか見る
3. 勝てる性質のどれを伸ばすかを書く

使われている場は、聞いた時点のものである。古くなったら、聞き直してこの表を書き換える。
