## 1. 目的と経緯

**回っている円盤を、誰かが押した瞬間に止めて、その人を決める。** 狙える遊びとして割り切る。

利用者の決定（2026-10-17）:

- **押した時刻で止まる席が決まる**（#401 の「実装時に決めること」10 の、結果をサーバーが先に決める案は採らない）
- **嘘では困る。押した人の画面で決まった人が、全員の画面に反映される**
- **押せるのは全員**
- **高速で回る円盤の点滅に配慮する**（WCAG 2.3.1）
- **1 人だけを決めるときだけの動き**（2 人以上・順番に回すとは組み合わせない）
- **キーボードでも押せる**

## 2. 実測した事実（main `087e6e0`）

- **当たりはサーバーが回す前に引く**（`startSpin`）。画面は `winnerIndex`・`settle` と経過から、止まる角度を逆算して減速の曲線を描く（`wheel-motion.ts` の `angleAt`）
- **画面ごとに回し始めの角度（`startDeg`）が違う。** 前に止まった位置から回し始めるため、同じ時刻でも画面によって円盤の向きが違う（止まる席だけが同じ）。
  → **押して止めるには、全画面で「いま指し針が指している席」が同じ時刻の関数になっている必要がある**（いまの作りではそうなっていない）
- **指し針の位置は並びで違う**（縦積みは下・横並びは右。`pointerDegFor`）。円盤の角度ではなく「指し針から見た位相」でそろえる必要がある
- 経過は「サーバーが送った `elapsedMs` ＋ 受け取ってからの時間」で出す（`elapsedOf`）。画面ごとのずれは、おおむね片道の遅延の差
- 決め方は `once`・`order` の 2 つ（#418）。脇の「決め方」の面に 2 つのボタンが等分で並ぶ
- 席の色は `--felt-700`・`--felt-800`・`--felt-900` の 3 段（どれも暗い緑）、字は `--ivory`、当たりは `--gold`
- 書体の base 層: 「止めて決める」「止める」「押して止める」「{名前} さんが止めました」「いま指している人」は通る。**「狙」「早」「減」「速」は外れる**

## 3. 設計の骨組み

```
回す（誰でも）──► サーバー: 回転を始める（止まる席はまだ無い）。位相の起点と回る速さを配る
                    全画面: 同じ位相の式で一定の速さで回す（指し針から見て同じ席を同じ時刻に指す）
押す（誰でも）──► 押した画面: その瞬間に指し針が指している席と、席の中の位置を、自分の画面の角度から出す
                    → roulette.stop { seq, index, settle } を送る。押した画面はその場で止まる
                    サーバー: その回転で最初に届いた押下だけを採る（妥当かを見る・P4）→ 結果を配る
                    ほかの画面: いまの角度から、決まった席の同じ位置まで短く動いて止まる（P3）
```

**結果を決めるのは押した人の画面**（利用者の決定）。サーバーは「最初に届いた押下」を採り、配るだけ。

## 4. 確認したいこと（推奨つき）

| # | 項目 | 推奨 | 理由 |
|---|---|---|---|
| P1 | **置き場と名前** | 「決め方」の 3 つ目に **「止めて決める」**。選ぶと選ぶ人数は出さない（1 人だけ）。ボタンが 3 つになるので、320 で 1 行に収まらなければ 2 段にする（モックで決める） | 1 人だけの動きなので、選ぶ人数の設定と並べない。「目押し」の「目」は書体に無い |
| P2 | **回り方** | 押されるまで**一定の速さ**で回り続ける。速さは**席が指し針を 1 秒に 4 つほど通る**くらい（席の数で 1 周の時間が変わる。モックで詰める） | 名前が読めて、狙えるが簡単すぎない。一定なので全画面で位相がそろう |
| P3 | **止まり方** | 押した画面は**押した位置でその場で止まる**（動かない＝嘘が無い）。ほかの画面は、決まった位置まで**近い向きに 0.5 秒ほどで動いて**止まる（1.5 席以内なら戻る、それより先なら進む） | 押した人の画面が正。ほかの画面は遅延の分だけずれているので、短く寄せる |
| P4 | **押下の妥当さ** | サーバーは、押下が届いた時刻のサーバーの位相から**遡って 1.5 秒ぶんの範囲**に入る席だけを受ける。範囲の外は `ROULETTE_STOP_INVALID` で拒む | 改造した画面が好きな人を送り込めないように。遅延が大きい端末も 1.5 秒までは通る |
| P5 | **誰も押さないとき** | **30 秒で自動に止まる**（サーバーが一様に引く。一言は「誰も止めなかったので、ルーレットが決めました」の類） | 回りっぱなしで部屋が止まらないように |
| P6 | **一周の規則** | 円盤に載せるのは**この一周でまだ選ばれていない人だけ**。全員選ばれたら周を閉じて全員に戻す | 狙えても、同じ人ばかりにはならない（#94 の前提を守る） |
| P7 | **点滅への配慮** | 回っている間、**席の色は暗い 3 段のまま**（明るさの差が小さく、WCAG の「点滅」の定義＝明るさの 10% 以上の行き来に当たらない）。真鍮の席は止まってからだけ。2 の速さの上限と合わせ、実画面で明るさを測って確かめる | 速く回っても、明るさが行き来しなければ点滅にならない |
| P8 | **動きを減らす設定** | 円盤を回さず、**「いま指している人: ○○ さん」の文字が一定の間隔（1 秒に 1 人ほど）で入れ替わる**。押すとその人に決まる | 回転を見せずに、同じ遊び（タイミングで止める）ができる |
| P9 | **キーボード** | 回っている間、主ボタンは「止める」になり、Enter・Space で押せる。**加えて、文字の欄に居ないときは Space でも止められる**（どこにフォーカスがあっても） | 回し始めた人以外はフォーカスが別の場所にある。フォーカスを勝手に動かさずに押せるように |
| P10 | **ほかの演出との関係** | #420（変わった止まり方）は掛けない | 押した位置と違う動きをすると嘘に見える |
| P11 | **配る窓** | 古い画面は止まる席を知らない回転を正しく描けない。決め方の切り替えが無いので、古い画面だけのルームでは起きない。混在中は「回しています」のまま止まらないように見えうる（再読込で直る） | #415・#418 と同じく、再読込と再起動で閉じる窓として受容する |

## 5. wire（案）

- 決め方に `press` を足す（`mode: 'once' | 'order' | 'press'`）
- 回転に `press: { phase0, seatsPerSec } ` を足し、止まったら `stop: { index, settle, by, atMs }` を載せる（止まるまで `winnerIndex` は意味を持たない。古い画面のために、止まった後は `winnerIndex`・`settle` に同じ値を入れる）
- コマンド `roulette.stop { seq, index, settle }`（strict）
- エラー `ROULETTE_STOP_INVALID`（範囲の外）。2 人目以降の押下は黙って捨てる（最初の押下で止まった後に届くのは普通のこと）

## 6. 検証（要点）

- 単体: 位相の式が全画面で同じ席を指す・押下の妥当さの範囲・最初の押下だけを採る・30 秒の自動停止・一周の規則
- 画面: 押した画面は動かない・ほかの画面は近い向きに寄せる・Space で止まる・動きを減らす設定の文字
- 点滅: 回っている間の円盤を撮り、指し針の周りの明るさの変化を測る（WCAG 2.3.1）
- E2E: 同じルームの通しに 1 回（A が回し、B が止め、A と B に同じ人）
- 変異: **340〜359**（#401 の「押して止める」）
