## 1. 目的と経緯

**回っている円盤を、誰かが押した瞬間に止めて、その人を決める。** 狙える遊びとして割り切る。

利用者の決定（2026-10-17）:

- **押した時刻で止まる席が決まる**（#401 の「実装時に決めること」10 の、結果をサーバーが先に決める案は採らない）
- **嘘では困る。押した人の画面で決まった人が、全員の画面に反映される**
- **押せるのは全員**
- **高速で回る円盤の点滅に配慮する**（WCAG 2.3.1）
- **1 人だけを決めるときだけの動き**（2 人以上・順番に回すとは組み合わせない）
- **キーボードでも押せる**

## 2. 実測した事実（main `087e6e0`）

- **当たりはサーバーが回す前に引く**（`startSpin`）。画面は `winnerIndex`・`settle` と経過から、止まる角度を逆算して減速の曲線を描く（`wheel-motion.ts` の `angleAt`）
- **画面ごとに回し始めの角度（`startDeg`）が違う。** 前に止まった位置から回し始めるため、同じ時刻でも画面によって円盤の向きが違う（止まる席だけが同じ）。
  → **押して止めるには、全画面で「いま指し針が指している席」が同じ時刻の関数になっている必要がある**（いまの作りではそうなっていない）
- **指し針の位置は並びで違う**（縦積みは下・横並びは右。`pointerDegFor`）。円盤の角度ではなく「指し針から見た位相」でそろえる必要がある
- 経過は「サーバーが送った `elapsedMs` ＋ 受け取ってからの時間」で出す（`elapsedOf`）。画面ごとのずれは、おおむね片道の遅延の差
- 決め方は `once`・`order` の 2 つ（#418）。脇の「決め方」の面に 2 つのボタンが等分で並ぶ
- 席の色は `--felt-700`・`--felt-800`・`--felt-900` の 3 段（どれも暗い緑）、字は `--ivory`、当たりは `--gold`
- 書体の base 層: 「止めて決める」「止める」「押して止める」「{名前} さんが止めました」「いま指している人」は通る。**「狙」「早」「減」「速」は外れる**

## 3. 設計の骨組み

```
回す（誰でも）──► サーバー: 回転を始める（止まる席はまだ無い）。位相の起点と回る速さを配る
                    全画面: 同じ位相の式で一定の速さで回す（指し針から見て同じ席を同じ時刻に指す）
押す（誰でも）──► 押した画面: その瞬間に指し針が指している席と、席の中の位置を、自分の画面の角度から出す
                    → roulette.stop { seq, index, settle } を送る。押した画面はその場で止まる
                    サーバー: その回転で最初に届いた押下だけを採る（妥当かを見る・P4）→ 結果を配る
                    ほかの画面: いまの角度から、決まった席の同じ位置まで短く動いて止まる（P3）
```

**結果を決めるのは押した人の画面**（利用者の決定）。サーバーは「最初に届いた押下」を採り、配るだけ。

## 4. 決定（2026-10-17 利用者が推奨を見て決めた）

| # | 項目 | 決定 | 理由 |
|---|---|---|---|
| P1 | **置き場と名前** | 「決め方」の 3 つ目に **「止めて決める」**。選ぶと選ぶ人数は出さない（1 人だけ）。**決め方のボタンはどの幅でも縦 1 列**（モック 1 版。3 等分は 320 で字が詰まり、自動の折り返しは 2 + 1 で据わりが悪い） | 1 人だけの動きなので、選ぶ人数の設定と並べない。「目押し」の「目」は書体に無い |
| P2 | **回り方** | 押されるまで**一定の速さ**で回り続ける。**1 秒に 20 席**（6 人なら 1 周 0.3 秒・24 人なら 1.2 秒） | **利用者がモック 3 版で決めた**（「もっと技術介入する感じ」。4・10 席では遅い）。一定なので全画面で位相がそろう |
| P3 | **止まり方** | 押した画面は**押した位置でその場で止まる**（動かない＝嘘が無い）。ほかの画面は、**勢いのまま前へ進み、決まった位置で減速して止まる**（戻らない。進む距離が短すぎて急に止まって見えるときは 1 周足す。止まるまでの時間は勢いから決め、0.35〜1.6 秒） | 押した人の画面が正。速いので遅延の分だけ何席もずれ、戻ると不自然（モック 2 版）。**通信の遅れは 0.3 秒ほどまで問題ない**（利用者） |
| P4 | **押下の妥当さ** | サーバーは**席の番号と席の中の位置の形だけ**を見る（0〜席数未満の整数・0 以上 1 未満）。外れたら `ROULETTE_STOP_INVALID` | 当初は「遡って 1.5 秒の範囲」の案だったが、**20 席/秒では 1 周が 1.2 秒以下**で、どの席も範囲に入り見分けられない。ルームの仲間を信頼する（#94 のゲストを足す操作と同じ線） |
| P5 | **誰も押さないとき** | **回し始めから 30 秒の時点で指し針が指している人に決まる**（起点の位置はサーバーが乱数で決めるので一様）。サーバーは時計を持たず、全画面とサーバーが同じ式で同じ人を出す。一言は「止める人がいませんでした」 | 回りっぱなしで部屋が止まらないように。時計を持たない分、再起動や取りこぼしに強い |
| P6 | **一周の規則**（#427 で撤回・ADR-0026 決定 4） | **使わない。** 円盤には入る人を全員載せる。一周の記録（`drawn`）も変えない（順番に回すと同じ扱い） | **利用者の決定**（推奨の「まだの人だけ」から変えた）: 「目押しで止めているので、同じ人ばかりにしようとすればできていい」 |
| P7 | **点滅への配慮** | 回っている間、**席の色は暗い 3 段のまま**（明るさの差が小さく、WCAG の「点滅」の定義＝明るさの 10% 以上の行き来に当たらない）。真鍮の席は止まってからだけ。2 の速さの上限と合わせ、実画面で明るさを測って確かめる | 速く回っても、明るさが行き来しなければ点滅にならない |
| P8 | **動きを減らす設定** | **このモードでは動きを減らす設定でも円盤を回す。** 回すのはこのモードを選んだときだけで、ほかの決め方はいまのまま（回さない） | **利用者の決定**（推奨の「文字が入れ替わる」から変えた）: 「円盤は回ってほしい。それが遊び心」。回転はこの遊びそのもので、動きが無いと成り立たない（WCAG 2.3.3 の「欠かせない動き」にあたる）。点滅の配慮（P7）はこの場合も守る |
| P9 | **キーボード** | 回っている間、主ボタンは「止める」になり、Enter・Space で押せる。**加えて、文字の欄に居ないときは Space でも止められる**（どこにフォーカスがあっても） | 回し始めた人以外はフォーカスが別の場所にある。フォーカスを勝手に動かさずに押せるように |
| P10 | **ほかの演出との関係** | #420（変わった止まり方）は掛けない | 押した位置と違う動きをすると嘘に見える |
| P11 | **配る窓** | 古い画面は止まる席を知らない回転を正しく描けない。決め方の切り替えが無いので、古い画面だけのルームでは起きない。混在中は「回しています」のまま止まらないように見えうる（再読込で直る） | #415・#418 と同じく、再読込と再起動で閉じる窓として受容する |

## 4.1 言葉（モックで決めた・base 層で実測済み）

止めて決める ／ 回っているルーレットを、押した瞬間に止めて決めます（決め方の面）／ 止めたところの人に決まります（回す前）／
止めると、指している人に決まります（回っている間）／ 止める（主ボタン）／ {名前} さんが止めました（止まった後。読み上げには「。{名前} さんに決まりました」を足す）／
止める人がいませんでした（30 秒で止まったとき）

止まった後の一言に決まった人の名前を並べると、1440 でも途中で切れた（モック 1 版）。名前は札が出し、読み上げにだけ入れる。

## 4.2 点滅（P7 の実測）

モック 2 版を 1440 で 1 秒 20 席で回し、円盤の中央の半分を 3 秒撮って明るさを測った。平均の明るさは 0.050〜0.057 でほぼ一定。
一度に明るさが 10% 以上変わる面積は最大 3,542 px（撮った面積の 4.4%。名前の字が通るところ）で、WCAG 2.3.1 の小さい面積の上限
（1024×768 で約 21,824 px）を下回る。

## 5. wire（実装した形）

- 決め方に `press` を足す（`mode: 'once' | 'order' | 'press'`）
- 回転に `press: { p0, rate, stop }` を足す。`stop` は止まるまで null、止まったら `{ index, settle, by, atMs }`（`by` は押した人・自動なら null）。
  止まったら `winnerIndex`・`settle`・`picks` を止まった位置にそろえる（古い画面と、1 人の結果を読む部品のため）。`durationMs` は 30 秒
- 30 秒の自動の停止は状態に書かない。`toView` と画面が `pressStopOf` で同じ値を出す（サーバーは時計を持たない）
- コマンド `roulette.stop { seq, index, settle }`（strict）。後から届いた押下・違う回転への押下は黙って捨てる
- エラー `ROULETTE_STOP_INVALID`（「ここでは止められません」）。位置の形が外れたときだけ
- 画面の同期フックは、同じ回転のうちに届いた中身（止まった位置）を採り、経過だけ古い基準のものを保つ

## 5.1 実装で決めたこと

- 押した画面は、サーバーの返事を待たずにその場で止まる。自分の押下が採られなかった（ほかの人が先）ときは、寄せる側になる
- 寄せ終わるまで札・一言・真鍮の席を出さない（局面は「寄せ終わったか」で決める）。止まった後に開いた画面は寄せない
- 押して止めるときの円盤の角度は、位置（席の単位）をその画面の指し針から見た角度にする（並びが違う画面どうしでも同じ席を指す）。
  そのため、回し始めに円盤の向きが前の止まった位置から跳ぶ
- お題の添え書きは 1 人を決める言い方（回っている間も）

## 6. 検証（要点）

- 単体: 位相の式が全画面で同じ席を指す・押下の妥当さの範囲・最初の押下だけを採る・30 秒の自動停止・一周の記録を変えない
- 画面: 押した画面は動かない・ほかの画面は近い向きに寄せる・Space で止まる・動きを減らす設定でもこのモードだけは回る
- 点滅: 回っている間の円盤を撮り、指し針の周りの明るさの変化を測る（WCAG 2.3.1）
- E2E: 同じルームの通しに 1 回（A が回し、B が止め、A と B に同じ人）
- 変異: **340〜359**（#401 の「押して止める」）

- 決め方のボタンが 3 つになったときの並び（P1）
