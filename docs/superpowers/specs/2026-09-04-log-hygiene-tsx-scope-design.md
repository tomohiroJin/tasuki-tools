## 3. 実測した事実（2026-09-04・main `5da22b4`）

### 3.1 「ブラウザの `console` は対象外」は ADR 0012 の初版から明文だった

`docs/adr/0012` 決定 D1 の末尾:

> ブラウザの `console` は本決定の対象外とする。journal は運用者とサーバーへ侵入した者の
> 双方が読みうるが、ブラウザの `console` は利用者本人しか見ない。脅威が異なるため規律を
> 分ける。ただし分類「秘密」の値をクライアントへ渡さないという制約は、ADR 0011 の分類表で
> 引き続き効く。

この一文は ADR 0012 を新設したコミット `1b4c8ef`（**2026-08-13**・#136）に含まれる。
#157 の起票は **2026-08-16** なので、**3 日前に決まっていた**。Issue の完了条件 **E1 は
既に満たされている**。

検査側の文言も追随済みで、現在は「ブラウザの console は ADR 0012 D1 が対象外と**決定済み**。
本検査が `.tsx` を走査しないこと自体の妥当性は別 Issue で判断する」と出す。
**残っている未決は後半だけ**である。

### 3.2 違反は 6 件ではなく 2 件

走査対象 9 パッケージの `src` 配下の `.tsx` は **48 件**（timer-web 36 / poker-web 9 / landing 3）。
本物の `findViolations` を当てると違反は **1 ファイル 2 行**だけだった。

```
apps/timer-web/src/ui/History.tsx:47  console
apps/timer-web/src/ui/History.tsx:64  console
```

Issue が挙げた `App.tsx` の 4 件は**現存しない**（#167「web の三層責務」の整理で消えた）。

**計測を 1 度誤った。** `findViolations(relPath, source)` の引数を逆に渡し「違反 0 件」を
得ていた。引数が逆でも例外にならず、`relPath` として渡ったファイル本文が
`ALLOWED_FILES.includes()` に一致せず、`source` として渡ったパス文字列に禁止構文が
無いため、**静かに 0 件**を返す。正しい順で当て直した値が上記である。

### 3.3 拡張子が「サーバか画面か」の代理になっていない

**検査はブラウザの `.ts` を走査しており、そこではブラウザの `console` にマーカーを要求している。**

| ファイル | 拡張子 | ブラウザの `console` | 検査の扱い |
|---|---|---|---|
| `apps/timer-web/src/sync/use-timer-sync.ts` | `.ts` | あり | **マーカー必須**（`ALLOWED_FILES` に登録済み） |
| `apps/poker-web/src/hooks/useSync.ts` | `.ts` | あり | **マーカー必須**（同上） |
| `apps/timer-web/src/ui/History.tsx` | `.tsx` | あり | **自由**（走査対象外） |

スクリプト自身のコメントが「`.ts` か `.tsx` かは『サーバか画面か』の代理にならない ——
ADR 0015 MUST 2 が求める同期フックは JSX を持たない `.ts` なので、画面から配線を移すだけで
拡張子が変わり、走査対象に入る」と書いているのに、**射程は拡張子で決まっている**。
配線を `.tsx` と `.ts` の間で移すだけで、検査の対象に入ったり出たりする。

### 3.4 許可の登録は、それ自身が走査の射程を守る

`findStaleAllowances` は「走査結果に無い許可ファイル」を赤にする。したがって
`History.tsx` を `ALLOWED_FILES` へ登録すると、**収集から `.tsx` を落とした瞬間に検査が赤くなる**。
射程を狭める変更が、列挙の側から自動的に止まる。

## 4. 決定

### D1: 検査は `.ts` と `.tsx` を区別しない

**走査対象の拡張子に `.tsx` を加える。** 理由は §3.3 —— 拡張子は「サーバか画面か」の
代理にならず、配線の置き場を変えるだけで射程が動くのは計測器として不健全である。

**規範（ADR 0012 D1）は変えない。** ブラウザの `console` は引き続き規律の対象外である。

### D2: ブラウザの `console` は規範上は自由だが、検査ではマーカーで明示する

D1 の帰結として、ブラウザの `console` は `ALLOWED_FILES` ＋ 行マーカーで通す。
**これは検査が規範より一段厳しい状態であり、意図的である。**

- 既に `.ts` 側（`use-timer-sync.ts` / `useSync.ts`）が同じ扱いを受けている。
  拡張子で扱いを変えないという D1 の裏返しである
- 「画面に `console` を足す」が**意図的な行為**になる。マーカーには理由を書く
- 規範を厳しくしているのではない。**規範が許すものを、検査が可視化している**

### D3: 未走査 `.tsx` の件数出力（#135 E7）は役目を終える

`.tsx` を走査するので未走査は 0 件になる。**常に 0 件を言い続ける出力は残さない。**
「見ていないものを黙っていない」という E7 の目的は、見るようにすることで果たされる。

### D4: `.mts` / `.cts` / `.jsx` は足さない

現在 0 件で実需が無い。足すと「今は 0 件だが将来のために」という列挙が増える。
**必要になったときに、そのとき足す。**

## 5. 設計

### 5.1 `scripts/audit-log-hygiene.mjs`

| 箇所 | 変更 |
|---|---|
| 走査する拡張子 | 純粋関数 `isScannedFile(name)` と宣言 `SCANNED_EXTENSIONS` として切り出し、`.ts`（`.d.ts` を除く）＋ `.tsx` にする |
| `readTsFiles` | `readSourceFiles` へ改名（`.tsx` も読むので実態に合わせる） |
| `countSkippedTsx` と E7 の出力 | 削除（D3） |
| `ALLOWED_FILES` | `apps/timer-web/src/ui/History.tsx` を追加 |
| docstring | 拡張子で射程を分けない理由（§3.3）と、D2 の「規範より厳しいのは意図的」を明記 |

**`isScannedFile` を切り出すのは、拡張子の集合を機械が検査できる形にするため。**
現在の自己テストは拡張子を一切主張していないので、**収集から `.tsx` を外しても自己テストは緑**になる。

### 5.2 `apps/timer-web/src/ui/History.tsx`

2 行に `// log-hygiene:allow ブラウザの devtools 向け` を付ける（既存 2 ファイルと同じ形）。

## 6. 検証

### 6.1 EARS

- **E1** THE ADR 0012 SHALL `.tsx`（ブラウザで動くコード）が決定 D1 の射程に入るかを明記する
  （**起票時点で充足済み**。§3.1。本 Issue は検査の射程を追記する）。
- **E2** THE ログ衛生の検査 SHALL `.tsx` を走査対象に含め、許可マーカーの無い直接の `console` を非ゼロで終了して名指しする。
- **E3** THE 検査 SHALL 走査していない `.tsx` の件数を出力しない（0 件になるため。D3）。
- **E4** WHEN 上記いずれかを壊す、THE CI SHALL 赤くなる（憲法 原則 VII の破壊検証で確認する）。

### 6.2 破壊検証の手順

**壊す前にコミットする。** 各項目で対照実行（壊さずに緑になること）を先に取る。

| # | 壊し方 | 期待 |
|---|---|---|
| 1 | `.tsx` にマーカー無しの `console` を足す | 赤（当該行を名指し） |
| 2 | `History.tsx` のマーカーを 1 つ消す | 赤 |
| 3 | `ALLOWED_FILES` から `History.tsx` を消す | 赤（許可の無いファイルの `console`） |
| 4 | 収集から `.tsx` を外す | 赤（`findStaleAllowances` が「走査結果に無い許可」を検知。§3.4） |
| 5 | 何も壊さない | 緑（対照） |

### 6.3 変異検査

`scripts/mutations/` へ 1 件（`pkg: "scripts"`）。`SCANNED_EXTENSIONS` から `.tsx` を落とす変異。
**落ちるのは自己テストである**（検査本体は §3.4 により赤くなるが、変異検査が見るのは
テストが恒真化していないことなので、拡張子を主張するテストを新設する）。

### 6.4 単体テスト

`scripts/audit-log-hygiene.test.mjs` に `isScannedFile` / `SCANNED_EXTENSIONS` のテストを足す。
