# Check-in Cards のやり方選択を揃った札の並びにする（#468・#463-A）— 設計

- **日付**: 2026-10-30・**実測時点**: main `9e9b8db9`
- **Issue**: #468（親 #463 のフィードバック 2・3・4・5）
- **前提**: [Check-in Cards の設計](2026-10-28-checkin-checkout-design.md) §4（選択）・§13（8 枚で並べる）、[レスポンシブ設計](2026-10-08-responsive-layout-design.md)（40rem・64rem）

## 1. 問題

- 横長の札を `auto-fill, minmax(19rem)` で並べており、説明文の長さで高さが 92〜134px にばらつく（#465 の撮影）
- 「戻る」はどこへ戻るのか、押すと何が起きないのかが伝わらない
- 側の切り替えがどの場の一覧かを示さない

## 2. 決めたこと

| # | 決定 |
|---|------|
| D1 | 札は縦の札（上に扇・下に題と説明）。グリッドは `grid-auto-rows: 1fr` で全札が同じ高さ・同じ幅 |
| D2 | 40rem 未満は 2 列（4 行）、40rem 以上は 4 列（2 行）。64rem 以上は扇・字を一段大きくする |
| D3 | 「ランダム」は末尾の 8 枚目。破線の枠と裏模様の扇で区別し、大きさは他と同じ |
| D4 | 側の切り替え（`.seg`）は札の真上。その側の使いどころを一文で添える。40rem 未満は横いっぱい |
| D5 | 「戻る」を見出しの行の右へ移し「いまの回に戻る」にする。回があるときだけ見出しの下に添え書きを出す |

### D5 の事実確認（実装前の読み）

`chooseMethod` / `drawMethod`（`packages/checkin-core/src/checkin.ts`）は `startRound` で `round` を新しい回に置き換える。札（`cards`）は空の Map になり、前の回の札は残らない。よって「選ぶと新しい回が始まります」は事実である。

一方、添え書きの括弧の言い方は Issue 案の「片付きます」を **「消えます」に直した**。「片」が書体の base 層に無く（`copy-fits-font-base.test.ts` が検出）、意味も「いまの回の札は消えます」で足りるため。文言は `選ぶと新しい回が始まります（いまの回の札は消えます）`。

## 3. 列数と札の寸法

| 画面幅 | 列 | 行 | 扇の札（幅×高さ） | 題 / 説明 |
|--------|----|----|-------------------|-----------|
| 40rem 未満（320〜639px） | 2 | 4 | 2.6×3.6rem | base / xs |
| 40rem 以上 64rem 未満 | 4 | 2 | 2.6×3.6rem | base / xs |
| 64rem 以上（会議室の投影） | 4 | 2 | 3.4×4.7rem | lg / sm |

列は `minmax(0, 1fr)` で、中身の長さが列幅を押し広げない（320px で横スクロールを出さない）。

## 4. 余白

| 場所 | 値 |
|------|----|
| 札どうしの間 | `--space-3` |
| 札の内側 | `--space-4` 縦 / `--space-3` 横（64rem 以上は縦 `--space-5`） |
| 扇と文の間 | `--space-3`（64rem 以上は `--space-4`） |
| 見出しの行（見出しと戻る） | 並びは部品 `.ui-page-header`（間 `--space-3`）。戻るは折り返しても `margin-inline-start: auto` で右端。添え書きは行の外（直後の兄弟）で全幅 |
| 切り替えと一文 | 切り替えの直下に詰める（一組） |

## 5. a11y

- 札のタップ領域は `min-block-size: var(--tap-target)` 以上（実際は縦の札で十分に大きい）
- 注意文（回があるとき）は **8 枚すべての札の `aria-describedby`** に、その札の説明の後ろへ併記する。一覧（`ul`）への結びは札にフォーカスしても読まれないため採らない。繰り返しになるが、札が消える注意は守る相手に届くことを優先する（Ruling）。側の一文は切り替えのグループの `aria-describedby`
- 札の名前は題、説明は `aria-describedby`（既存のまま）。扇は `aria-hidden`
- 「いまの回に戻る」は押すと回を変えず卓の画面へ戻り、フォーカスを問いの見出しへ移す（既存の `useLandingFocus`）
- 動きを減らす設定の持ち上げの止め方（`.method-option:hover`）は変えない
- 文言はすべて base 層に収める（`copy-fits-font-base.test.ts`）
