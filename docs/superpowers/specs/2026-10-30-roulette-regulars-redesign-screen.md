# #469（#463-B）いつものメンツを「いまの人」から作り、チェックで作る・直す — 画面案

> 前提は [`2026-10-29-roulette-regulars-screen.md`](2026-10-29-roulette-regulars-screen.md)（#458）。
> この文書はその「作る・直す欄」と「入れた結果の知らせ」だけを差し替える。置き場所・札・消す確認・文言の方針は #458 のまま。
> 端末の保存の形式（`tasuki.roulette.regulars` 版 1）とサーバーとの通信は変えない。

## 0. 使う場面

1. **会の前に用意する**: 先週と同じ顔ぶれが揃ったところで「いまの人から作る」。チェックの付いた全員がそのまま組になる
2. **会の最中にさっと入れる**: 組の札を一度押す。結果（入った・もう入っていた・入らなかった）が、入らなかった人の名前つきで分かる
3. **入れ替わったので直す**: ルーレットに出ている人を見ながら、チェックで足し引きする

## 1. 決めたこと（D1〜D6）

| 番号 | 決めたこと | 理由 |
|---|---|---|
| D1 | 「追加した名前から作る」を「**いまの人から作る**」に置き換える。名簿＋ゲストの全員（同名は 1 人）を候補にし、いまルーレットに入っている人にチェックを付けて開く | 旧は追加したゲストしか写せず、名簿の人（自分を含む）を組にできなかった |
| D2 | 欄は二段。上は「**ルーレットにいる人**」のチェックの一覧、下は「**ほかの名前（1 行に 1 人）**」の手入力。組はチェック＋手入力（保存と同じ正規化で重複を除く）。人数表示は合計 | いない人も組に入れたい（手入力は残す）が、いる人を打ち直させない |
| D3 | 直すときは、組の名前のうち候補にいる人はチェック、いない人は手入力へ。照合は保存と同じ正規化・大小無視 | 大小や全角半角の違いで同じ人が両方に出ると二度入る |
| D4 | 「新しく作る」は残す。チェックは全部外れ、手入力は空で開く | 今いない人だけで作る・まっさらから作る場面 |
| D5 | 入れた知らせは、数に加えて**上限で入らなかった人の名前**を出す。もう入っていた人は数のみ。知らせは組の行の近く（常設の `role="status"`）に出す | 入らなかった人こそ次の行動（誰を外すか）に要る情報。もう入っている人は名前を出しても行動が変わらず、長くなるだけ |
| D6 | 区画の位置（「名前を追加」の下）は変えない | 「名前を追加」も組の札も「人を足す操作」。同じ面の末尾に一塊で置けば、探す場所が 1 つで済む。上の一覧の行は人の出入りで動くが、区画は末尾なので動かされない |

## 2. 画面

欄を開いたときの並び（作る・直す共通）。

```
いつものメンツ                この端末だけ
「朝会」を直す                           ← 欄の題
メンツの名前   [朝会                  ]
ルーレットにいる人                        ← fieldset の legend
 [✓] あや
 [ ] さとう
 [✓] すずき                               ← 行全体がラベル・44px・14rem で縦スクロール
ほかの名前（1 行に 1 人）
 [いない人                           ]    ← textarea（一覧があるとき 3 行・無いとき 6 行）
 3 / 24 人                                 ← 合計（チェック＋手入力・重複除く）
                       [やめる][この端末に保存]
 [このメンツを消す]                        ← 直すときだけ
```

- **人が 1 人もいない**: 「ルーレットにいる人」の一覧は出さず、手入力だけ（行数は 6）。「いまの人から作る」のボタンも出さない
- 欄を開いている間、一覧は**開いた時点のスナップショット**。途中で人が出入りしても、押そうとしたチェックが動かない（保存に使う名前も開いたときのもの）
- 名前が長いときは `…` で切る。行は縮められる（`min-width: 0`）。一覧の最大の高さを決め、20 人を超えても欄が画面を押し流さない

## 3. 操作の流れ

- **いまの人から作る** → 欄が開き、候補の全員が出て入っている人にチェック、手入力は空、フォーカスは「メンツの名前」。保存すると札にフォーカス
- **新しく作る** → チェックは全部外れ、手入力は空
- **直す** → 組の名前を振り分けて開く。チェックを外して保存すると組から外れる
- **保存の検証**: チェックと手入力の合計（重複を除く）が 0 人なら「名前を 1 人から入れてください」、24 人を超えたら「1 組は 24 人までです」。**保存せず**理由を `role="alert"` に出し、欄は閉じない（超えた人数は人数表示 `25 / 24 人` で見える）
- **入れる** → 知らせを組む。例:
  - `6 人を入れました。名前は 24 人まで追加できます。3 人は入りませんでした（さとう、Bob、ｱﾘｽ）`
  - `名前は 24 人まで追加できます。入れられませんでした（A、B）`
  - `6 人を入れました。2 人はもう入っているので、とばしました`（名前は出さない）
  - 末尾の「入る人がいま N 人です…」は #458 のまま

## 4. 候補の作り方（純関数・`regulars-view.ts`）

| 関数 | 役目 |
|---|---|
| `candidatesOf(rows)` | 名簿＋ゲストの行から候補を作る。名前は保存と同じ正規化、同名（大小・全角半角・前後の空白）は先に出た 1 人にまとめ、どちらかが入っていればチェック。見えない名前は落とす |
| `splitForEdit(candidates, members)` | 組の名前を候補のチェックと手入力に振り分ける |
| `buildMembers(checked, text)` | チェック（先）と手入力（後）から、保存と同じ正規化・重複除去で組の名前の列を作る（`parseMemberLines` の再利用） |
| `planBatch` / `batchNoticeText` | 入らなかった人の名前（`overflowNames`）を含める |

### 入れるときに外れている人を戻す（レビュー指摘）

- サーバーの `addMany` は同名をとばすだけで、外れた人はルーレットに戻らない。そこで画面が `restoreOf` で「同名の行がどれも外れていて、押せる行がある」人を選び、既存の `roulette.include` を送って戻す（通信は変えない）
- 同名の行のどれか 1 つでも入っていれば「もう入っている」。押せる行が無い人だけ「いま戻せません」
- 比べ方はサーバーと同じ `conflictsWithExisting`（名簿の表示名・ゲスト・束の名前はサーバーが入室・追加時に正規化済み）
- 戻すのは `addMany` と別のコマンドなので、知らせは**送った時点の見込み**（`planBatch` と同じ扱い）。入る人の数には戻した分も足す
- 「いまの人から作る」は、自分以外に候補がいる（候補が 2 人以上）ときだけ出す

## 5. 文言（すべて base 層に収まることを `copy-fits-font-base.test.ts` が見る）

| 場所 | 文言 |
|---|---|
| ボタン | いまの人から作る |
| 一覧の legend | ルーレットにいる人 |
| 手入力のラベル | ほかの名前（1 行に 1 人） |
| 知らせの末尾 | `（${名前を「、」でつなぐ}）` |

## 6. 320px の収まりと a11y

- 区画は 1 列（`minmax(0, 1fr)`）。チェックの行は `min-width: 0`・名前は `…`。ボタンは折り返す。確認は 320 / 1280 の `scrollWidth` で E2E が見る
- チェックの一覧は `<fieldset><legend>`＋`<ul>`、行全体が `<label>`（押せる面は 44px）。人数表示は `aria-describedby` で結ぶ
- 検証エラーは `role="alert"`、手入力に `aria-invalid`。既存の `role="status"` は区画に 1 つのまま増やさない
- フォーカス: 開く → 名前の欄／閉じる → 開いた札／保存 → その組の札（#458 のまま）

## 7. 採らなかった案

- **欄を開いている間も人の出入りを一覧へ反映する**: 押そうとした行が動く。スナップショットで足りる
- **もう入っていた人の名前も出す**: 長くなるだけで、取れる行動が変わらない
- **チェックの一覧を常に全員 + 組の名前を別に持つ**: 保存の形式を変えずに済むよう、保存は名前の列のまま
