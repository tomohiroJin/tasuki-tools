## 1. 目的

**回すたびに 1 人ずつ円盤から抜けていき、最後に残った人に決まる、緊張感のある決め方を選べるようにする。**
全員の画面で同じ人が同じ順に抜け、同じ人が残る（#94 から変えない）。

#401 の言葉: 「チームとして、回すたびに 1 人ずつ抜けていく緊張感のある決め方を選べる」

**今の決め方（1 回で決める）の画面と動きは変えない**（#415 で 1 人・2〜4 人とも利用者が承認した画面）。
新しい決め方は、選んだときにだけ現れる。

## 2. 実測した事実（main `2b40f11b`）

- 回転は 1 回で完結する。複数の回転にまたがる状態は無い（`lastSpin` は最後の 1 回だけ）
- 選ぶ人数 `pickCount`（1〜4）はルームで共有する。人数の切り替えは脇の「ルーレットに入る人」の見出しの下（`PickCountPicker`）
- 当たりは一周の規則（`drawPicks`）でサーバーが引く。乱数源はポート越し（`node:crypto`）
- 回転の長さは core の表（`pickStopsMs`・`spinDurationMs`）が正本。画面とサーバーが同じ表を読む
- 「選ばれた」の印・一周の数・真鍮の席・札は「何人目まで決まったか」（`revealedCountOf`）1 つで切り替わる
- 円盤の席は回転のときの並び（`spin.wheel`）で描き、次に回すまで変えない
- 書体の base 層の実測（`outsideBase`）:
  - 通る: 決め方・1 回で決める・1 人ずつ抜く・抜けた・抜ける順・抜けた順 3・残り 5 人・最後に残った人・最後まで残った 2 人・次の 1 人を抜く・この回をやめる・途中から入った人は次の回から入ります・1 人ずつ抜いていき、最後に残った人に決まります・残った人が次の進行役です・脱落・生き残り
  - **外れる**: 「減」（「減っていく」）・「勝」（「勝ち残り」）。**画面の言葉に使わない**（モードの呼び名は「1 人ずつ抜く」）

## 3. 範囲

### この設計で行うこと

- 脇に「決め方」の切り替え（「1 回で決める」／「1 人ずつ抜く」）を足す
- 「1 人ずつ抜く」では、回すたびに 1 人が抜け、**残りが選ぶ人数（1〜4）になったら終わり**、残った人に決まる
- 抜けた人と順番を、脇の一覧と円盤で見せる。途中で「この回をやめる」ができる

### やらないこと

- 目押しモード（#401 の候補 3）
- 抜けた順をそのまま発表の順番などに使う機能（順番は見せるが、結果は「残った人」）。順番を決める用途は実需が出てから
- 結果を timer の交代の輪へ渡す（#401 本文のとおりスコープ外）

## 4. 決定（案。§10 の問いへの答えで確定する）

| # | 決定（案） | 理由 |
|---|---|---|
| K1 | **「決め方」をルームの状態に持つ**（`mode: 'once' \| 'knockout'`・既定 `once`）。新しいコマンド `roulette.mode.set` で変える。選ぶ人数と同じく全員で共有 | 2 つ目の遊び方が来たので、multi-pick spec M1 の「モードの列挙は実需が出てから」の実需にあたる。人数とは別の軸（1 人ずつ抜いて 2 人残す、ができる） |
| K2 | **結果は「最後に残った k 人」**（k = 選ぶ人数。k = 1 なら次の進行役） | 「1 回で決める」と結果の意味（選ばれた人）がそろい、札・一言・一周の数をそのまま使える。抜けた順は脇の一覧に添えて見せる |
| K3 | **残る人（結果）は回を始めた時点に一周の規則で決め、サーバーだけが持つ。** 毎回の「抜ける人」は、残る人以外の残りから一様に引く | 結果の分布と一周の規則（全員が一周するまで同じ人は選ばれない）が「1 回で決める」とまったく同じになる。抜けていく様子は見せ方で、公平さを崩さない。**残る人は回が終わるまで wire に載せない**（途中で画面やブラウザの道具から先に分からないように） |
| K4 | **回は複数の回転にまたがる状態としてルームに持つ**（`round: { wheel, eliminated, survivors(サーバーだけ), k }`）。揮発（ADR-0007）。再起動で回は消え、何も起きなかったことになる | 1 回の押下で 1 人ずつ抜けるので、回転をまたいで「誰が残っているか」が要る |
| K5 | **1 回押すと 1 人抜ける**（主ボタンは「1 人抜く」）。最初の押下で回が始まる。誰が押してもよい（今の「回す」と同じ） | 1 人ずつ間が空くことが、このモードの緊張感そのもの。全部を自動で続けると、24 人で 1 分以上ただ見ていることになる |
| K6 | **抜けた席は、次に回す前に円盤から消して詰める**（回っている間は並びを変えない） | 「減っていく」ことが円盤の上で見える。沈めて残す案は、終盤に細い席ばかりになり、残りが読めない |
| K7 | **回の途中で入ってきた人は、その回には入らない**（次の回から入る）。**途中で抜けた人**（離席・外した・名前を消した）は、まだ残っていれば回から外す。それが残る人なら、残りから一周の規則で引き直す。残りが k 人以下になったらそこで回を終える | 途中で円盤の席が増えると「抜けた人数」と合わなくなる。抜けた人を回に残すと、居ない人が最後に残りうる |
| K8 | **回の途中は「決め方」と「選ぶ人数」を変えられない**（画面は押させず、サーバーも `ROULETTE_ROUND_IN_PROGRESS` で拒む）。「この回をやめる」で回を終える（何も決まらず、一周の記録も変えない） | 途中で k が変わると、残る人の決め直しが要る。やめる道があれば変えたいときに困らない |
| K9 | **1 人を抜く回転の長さは、まず今と同じ 4 秒**。モックで、人数が多いとき（例: 12 人で 11 回）に長く感じるかを見て、短い回転（例: 2.5 秒・2 周）にするかを決める | 先に長さを変えると、1 回で決めるときと手触りが分かれる。決めるのは見てから |
| K10 | **「1 回で決める」の画面と動きは #415 から変えない**（1 人・2〜4 人とも）。差分は「1 人ずつ抜く」の分岐にだけ置く | 利用者の「崩れないように」。#415 で画素の比較を検査にした形を続ける |

### 退けた案

| 案 | 退けた理由 |
|---|---|
| Z1 毎回、残りの全員から一様に抜く（残る人を先に決めない） | 結果の分布が一周の規則から外れ、さっき進行役をした人が最後に残りうる。「同じ人ばかり当たらない」（#94）を崩す |
| Z2 1 回押すと最後まで自動で続ける | 人数が多いと長く、途中で誰も手を出せない。1 人ずつの間が無くなる |
| Z3 抜けた席を沈めて円盤に残す | 終盤に細い席ばかりになり、残りの人が読めない。「減っていく」が見えにくい |
| Z4 最初に抜けた人を当たりにする | 1 回目で決まってしまい、残りの回転が意味を持たない。「1 回で決める」と変わらない |
| Z5 残る人を wire に載せ、画面が隠す | ブラウザの道具や古い画面から先に分かる。隠すのはサーバーの方が確か |

## 5. 設計（要点）

### 5.1 `packages/roulette-core`

- 状態に `mode`（既定 `once`）と `round`（回の途中だけ。`null` が既定）を足す
- `startKnockoutSpin(state, input)`:
  - 回が無ければ回を始める: 入る人を凍結（`wheel`）し、`drawPicks(k)` で残る人を引く（一周の規則）。入る人が k + 1 人未満なら拒む
  - 回の残り（`wheel − eliminated − 途中で抜けた人`）から、残る人を除いて一様に 1 人を引き、`eliminated` に足す。`lastSpin` はその人の席に止まる 1 回の回転（今の `Spin` の形のまま。`picks` は 1 件）
  - 残りが k 人になったら回を終える: `drawn` を更新し（一周の規則）、`round` を閉じて結果を `lastSpin` に添える（`survivors`）
- `setMode`・`abortRound`・`pruneRound`（途中で抜けた人の扱い・K7）
- `toView`: `mode` と `round`（`wheel`・`eliminated`・`remainingCount`。**`survivors` は回が終わるまで載せない**）
- 回転中の判定・回転の長さは今の表（`pickStopsMs(1)`）を使う。K9 で短くするなら表に 1 行足す

### 5.2 同期サーバー

- `roulette.spin` は `mode` で分岐する。`roulette.mode.set`・`roulette.round.abort` を足す
- 名簿が変わったとき（退出・離席）に `pruneRound` を通す（今の `prune` と同じ場所）

### 5.3 wire

- フレームに `mode`・`round` を足す（省略可。古いサーバーは載せない）
- コマンド `roulette.mode.set { mode }`・`roulette.round.abort` を足す（strict）
- **配布の窓**: 古い画面 × 新しいサーバーでは、回の途中の回転を「次の進行役は（抜けた人）さんです」と読んでしまう。決め方を変えられるのは新しい画面だけなので、窓は古い画面と新しい画面が同じルームに居るときだけ開く。再読込で閉じる（`deploy/roulette/NOTES.md` に書く）

## 6. 見た目（崩さないための決め）

**モックで確かめてから実装する**（multi-pick と同じ手順）。案の骨組み:

```
脇（ルーレットに入る人）            舞台（回の途中・残り 4 人・k = 1）
┌───────────────────────┐        ┌────────────────────────────┐
│ 決め方                │        │   ╭─────────╮               │
│ [1 回で決める][1 人ずつ抜く] │        │  │ 残り 4 席 │ ◀  ┌─伏せた札─┐ │
│ 選ぶ人数               │        │   ╰─────────╯     └─────────┘ │
│ [1 人][2 人][3 人][4 人]   │        │  あおい さんが抜けました（残り 4 人） │
│ ☑ あおい   抜けた 1      │        │  [ 1 人抜く ]  この回をやめる     │
│ ☑ 健太                │        └────────────────────────────┘
└───────────────────────┘
```

- **決め方の切り替え**は「選ぶ人数」の上に、同じ部品（副のボタン `--sm` ＋ `aria-pressed`）で 2 つ。1 行目にラベル、2 行目にボタン（multi-pick spec §6.4 と同じ置き方）。320px で 2 つのボタンが 1 行に収まるかをモックで測る
- **円盤**: 回の途中は「残っている人」だけの席。抜けた人の席は、止まった後に真鍮ではなく沈んだ色で一度示し、次に回す前に消して詰める
- **札**: 回の途中は伏せたまま（結果がまだ無い）。回が終わったら、今の札（1 人）・組の札（2〜4 人）でめくる
- **一言**: 回す前「1 人ずつ抜いていき、最後に残った人に決まります」→ 回っている間「{名前} さんが回しました」→ 抜けた後「{名前} さんが抜けました（残り {n} 人）」→ 終わり 今の結果の一言（「次の進行役は ○○ さんです」「選ばれたのは …」）
- **主ボタン**: 「1 人抜く」。その横に控えの「この回をやめる」（回の途中だけ）
- **脇の一覧**: 抜けた人に印「抜けた {順}」。途中から入った人には印「次の回から」
- 320×640 の縦の予算（円盤・札・下端の帯が 1 画面）に、控えのボタンが入るかをモックで測る。入らなければ「この回をやめる」を脇へ置く

## 7. 配布

本番への配布は利用者の明示の指示を待つ。サーバー → web の順（multi-pick と同じ）。

## 8. 検証（要点）

- **EARS**: 回を始めたときに残る人が一周の規則で決まる／回の途中で残る人が wire に出ない／1 押下で 1 人抜け、全画面で同じ人が抜ける／残りが k 人で回が終わり、結果と一周の記録が「1 回で決める」と同じ形になる／途中の入退室（K7）／途中で決め方・人数を変えられない（K8）／やめると何も変わらない／**「1 回で決める」の画面は #415 から変わらない**
- **単体**: 残る人の分布が「1 回で決める」と同じこと（偽の乱数で全組を回す表）・`toView` に残る人が出ないこと・`pruneRound` の表
- **変異**: 320〜339 を #401 の「1 人ずつ抜く」に割り当てる（300〜319 は複数人決定）。残る人を wire に出す・回を閉じたときに `drawn` を更新しない・途中で抜けた残る人を引き直さない、など
- **画面の比較**: 「1 回で決める」の 1 人・2 人の舞台を、#415 の撮り方で前後比較する
- **E2E**: 同じルームの通しに「1 人ずつ抜く」を 1 回足す（上限 90 秒に収まるよう、入る人を少なくする）

## 9. 見積もりと見送りの判断材料

- **複数人決定より大きい。** 回転をまたぐ状態（回）・途中の入退室・やめる操作・決め方の切り替えが増える。見込みは core ＋ 同期サーバーで 1 PR、画面で 1 PR、モックの往復 1〜2 回
- 結果の決め方（K3）は「1 回で決める」と同じなので、**公平さの検査は今の抽選の検査に乗る**。新しく守るのは「途中で先に分からない」「途中の入退室」の 2 つ
- 見送るなら: 「1 回で決める」に、止まる前に席を 1 つずつ沈めていく演出だけを足す案（Z6）もある。状態は増えないが、押す人が手を出せる緊張感は出ない
