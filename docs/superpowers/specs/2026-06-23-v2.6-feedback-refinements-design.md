# v2.6 実機フィードバック リファインメント 設計

- 日付: 2026-06-23
- 対象: `tdd-mob-pro-timer/apps/web`（core 変更なし）
- 種別: UX 改善＋バグ修正（v2.5 実機フィードバック3点）
- 方針: 方針A（既存パターンに沿った的を絞った改修・象徴ビジュアル `TeamOrbit` は維持）

## 背景（v2.5 実機フィードバック）

1. **お題を使う/使わないが分かりにくい** — 「お題・設定」タブの AI 解錠の下に埋もれた小さなチェックボックスで、見つけにくく・モード選択に見えない。
2. **交代音が全く鳴らない・音量調整なし・音登録もない** — 設計以前にバグ。①`playTones` が毎回新しい `AudioContext` を生成し `resume()` しないため、自動再生ポリシーで**タイマー発火の音がブロック**される。②音量調整 UI なし。③`voice` は無効プレースホルダで実音源が同梱されていない。
3. **交代表示は改善したが文字が小さい** — 並び順ストリップと「あなた: あと N人」が `text-xs` で見にくい。

## ユーザー確定事項

- #1: 弱いチェックボックス→**明示セグメント「お題あり/なし」**、配置は**「ルーム」タブの開始ボタン近く**（決める場所を移す）。
- #2: **実音源を同梱（合成＋実ファイル両方）＋音量スライダー＋試聴/交代が確実に鳴る AudioContext 修正**。アップロード登録は**見送り**。
- #3: **「あなたの番」サマリを強調＋現/次ドライバー強化＋交代周りタイポの底上げ**。

## #1 お題あり/なしセグメント（配置移動＋明示化）

### 要件
- ホストが開始前に必ず見る「ルーム」タブの**開始ボタン直下**に、明示的セグメント切替「お題あり / お題なし」を置く。
- 弱いチェックボックス（お題・設定タブ内）は廃止。お題・設定タブのお題セクションは `problemEnabled` に連動表示（現状維持）。

### 設計
- `apps/web/src/ui/Lobby.tsx`:
  - 「ルーム」タブの `startButton` 直下（host のみ）に新コンポーネント `<ProblemModeToggle enabled={problemEnabled} onChange={(v) => onConfigSet?.({ problemEnabled: v })} />` を配置。
  - 非ホストには出さない（ホストの設定が snapshot で全員に反映される）。
  - お題・設定タブの旧チェックボックス（Task8 で追加したもの）は削除。
- 新コンポーネント `apps/web/src/ui/components/ProblemModeToggle.tsx`:
  - `role="radiogroup" aria-label="お題の使用"` のセグメント2択（「お題あり」「お題なし」）。アクセシブル名は各ボタンに付与。現在値を `aria-checked`/視覚強調で示す。
  - 補足ヒント1行（例: お題ありは課題を出題、お題なしは自由に開始）。
  - props: `{ enabled: boolean; onChange: (enabled: boolean) => void }`。純粋表示＋コールバックのみ（localStorage や WS は持たない）。
- core/サーバーは変更なし（`config.set { problemEnabled }` は v2.5 で修正済み・往復テスト済み）。

### 単体テスト
- `ProblemModeToggle`: enabled=true で「お題あり」が選択状態。クリックで `onChange(false)` 発火。
- Lobby: ルームタブにトグルが出る（host）／非ホストでは出ない。お題・設定タブの旧チェックボックスが無い。

## #2 交代音（AudioContext 修正＋実音源＋音量）

### 要件
- 交代時・試聴の**両方で確実に鳴る**（自動再生ポリシー回避）。
- **音量スライダー**（個人設定・localStorage 永続・即反映）。
- **実音源を同梱**（合成音＋実ファイルの両系統）。アップロードは作らない。

### 設計
- **AudioContext 基盤（`platform/sound.ts` 改修）**:
  - モジュール単位で**単一 AudioContext を遅延生成**する `getSharedAudioContext()`。
  - `installAudioUnlock()`: `window` に **一度だけ**の `pointerdown`/`keydown`/`touchstart` リスナーを張り、発火時に `ctx.resume()` して unlock（以後リスナー解除）。`apps/web/src/main.tsx`（または App マウント）で呼ぶ。
  - `playTones(freqs, opts)` は**共有コンテキストを再利用**（毎回 new しない）。`closeContextSoon` は廃止（共有のため閉じない）。
  - 音量を全経路に伝播: `playChime(soundId: string, volume: number)`。合成音は `gain` に `volume` を乗算、ファイル音は `HTMLAudioElement.volume = volume`。
  - 合成チャイムは**聞こえる音量・長さ**へ調整（極小だった `soft` 等の底上げ）。
- **実音源の同梱**:
  - `apps/web/public/sounds/` に実チャイムを**ffmpeg で生成しコミット**（例: `ping`・`bell`・`knock` の mp3）。生成は `scripts/gen-sounds.sh`（ffmpeg のサイン/減衰合成）で再現可能にし、生成物もコミット（CI/別環境で鳴るように）。
  - registry `CHIMES` を **合成3種（`chime-up` 上昇2音／`chime-down` 下降2音／`soft` ソフト）＋ファイル3種（`ping` ピンポン／`bell` ベル／`knock` ノック）= 計6種**に再構成。**全て `isReady:true`**。`VOICE_ASSET_READY` の無効プレースホルダは廃止。既定は `chime-up`。
  - ファイル音は `import.meta.env.BASE_URL + "sounds/<name>.mp3"` で参照（base path 安全）。
- **個人設定に音量追加（`prefs/local-prefs.ts`）**:
  - `NotifyPreferences` に `volume: number`（0–1, 既定 0.6）追加。`loadNotifyPreferences` の欠損補完・破損フォールバックに含める。後方互換（旧データに volume が無くても既定補完）。
- **設定 UI（`ui/components/NotifySettings.tsx`）**:
  - 音量スライダー（`<input type="range" min=0 max=1 step=0.05 aria-label="音量">`）を追加。変更で `saveNotifyPreferences`（既存のカスタムイベントでライブ反映）。
  - 試聴ボタンは `playChime(soundId, volume)` を呼ぶ（unlock 済みコンテキストで鳴る）。チャイム選択ドロップダウンは全 `isReady` 音源を出す。
- **発火経路（`ui/use-switch-alert.ts`）**: 既存どおり交代時に `playChime(notify.soundId, notify.volume)` を呼ぶよう volume を渡す。ソロ（1人）では交代が起きないため鳴らないのは仕様（試聴で確認可能）。

### 単体テスト
- `local-prefs`: volume の保存/読み戻し・欠損補完（旧データ→既定0.6）・破損フォールバック。
- `sound`: `playChime(id, volume)` が未知 id でも例外を投げない。registry が全て `isReady:true`・id ユニーク。AudioContext 無し環境（jsdom）でも例外なし。
- `NotifySettings`: 音量スライダー変更で `volume` が localStorage に保存される。試聴で `playChime` がモック呼び出しされる（選択 id＋現在 volume）。
- `useSwitchAlert`: 交代時に `playChime` が `(soundId, volume)` で呼ばれる（既存テスト更新）。

> 注: AudioContext unlock そのものの「実際の発音」は jsdom では検証不可。ユニットは「呼び出し・引数・例外なし」を保証し、**実発音は実機検証**で担保する。

### 単体テスト

## 影響範囲とリスク

- **core/サーバー変更なし**。すべて `apps/web` 内。
- **新規バイナリ資産**: `public/sounds/*.mp3`（ffmpeg 生成・コミット）。生成スクリプトも同梱し再現可能に。
- **localStorage**: `NotifyPreferences` に `volume` 追加（後方互換・既定補完）。
- **AudioContext**: 単一化＋unlock は既存挙動を置換（毎回 new を廃止）。`playSwitchChime` 後方互換は維持（`playChime("chime-up", 既定volume)` 委譲）。
- リスク: 自動再生ポリシーはブラウザ差あり。unlock は標準的な「初回ユーザー操作で resume」パターンで対応。実機（Chrome/Firefox/Safari 系）で発音確認を完了条件に含める。
