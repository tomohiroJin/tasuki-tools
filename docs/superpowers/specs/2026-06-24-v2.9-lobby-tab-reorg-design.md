# v2.9 ロビー タブ再編（関心の分離） 設計

- 日付: 2026-06-24
- 対象: `tdd-mob-pro-timer/apps/web`（core/サーバー変更なし）
- 種別: UX 改善（ロビーのタブ構成の再編・実機フィードバック1点）
- 方針: 既存パターン準拠の的を絞った改修。`ConfigPanel` を関心ごとに2分割し、タブ間で項目を振り分け直す。

## 背景（実機フィードバック）

ロビーのタブが「ルーム」「お題・設定」の2つだが、**「お題・設定」にセッション設定（交代間隔・詳細設定）とお題が混在**し、**「ルーム」にお題あり/なしトグル**があって関心が分かれていない。次の整理で使いやすくする:

- セッション設定（交代間隔・詳細設定）を **ルーム** タブへ。
- お題まわり（あり/なしトグル・お題本体）を **お題** タブへ。
- 言語/難易度/言語プールは**お題生成パラメータ**なので **お題** タブに置く。
- タブ名「お題・設定」→ **「お題」**。

狙い: **ルーム＝部屋＋セッション操作**（開始・交代間隔・詳細・招待・通知・参加者）、**お題＝お題まわり**（あり/なし・言語/難易度・AI解錠・お題本体）という明確な関心の分離。

## ユーザー確定事項

- 「お題あり・なし」トグルは **お題タブの先頭**（その下に言語/難易度/お題本体が続き、お題まわりをこのタブで束ねる）。
- 交代間隔・詳細設定は **ルーム** タブ（開始ボタンの直下、招待カードの上）。
- 言語/難易度/ランダム言語プールは **お題** タブ（お題あり/なしの直下）。
- タブ名は「お題」。

---

## 核となる構造変更：ConfigPanel の2分割

現在の `ConfigPanel`（250行）は「言語/難易度/ランダム言語プール」＋「交代間隔/詳細設定（ナビゲーター・強い交代通知・休憩リマインダ）」を1コンポーネントに混載している。`problemEnabled` ゲートは前者（言語/難易度/プール）だけに掛かっており、関心は元から2つに分かれている。これを2コンポーネントに分割する:

- **`ProblemConfigPanel`**（新規 `components/ProblemConfigPanel.tsx`）
  - 内容: 言語（＋ランダム）/ 難易度（＋ランダム）/ ランダム対象の言語プール。
  - `problemEnabled=false` のときは中身（言語/難易度/プール）を出さない既存挙動を維持。
  - props: `{ config: SessionConfig; onChange: (patch: Partial<SessionConfig>) => void; problemEnabled: boolean }`（現 ConfigPanel と同じ型のサブセット）。
- **`SessionConfigPanel`**（新規 `components/SessionConfigPanel.tsx`）
  - 内容: 交代間隔（3/5/7/10/15分）/ 詳細設定（ナビゲーター・強い交代通知・休憩リマインダ、折りたたみ・既定OFF）。
  - props: `{ config: SessionConfig; onChange: (patch: Partial<SessionConfig>) => void }`。
- 既存 `ConfigPanel.tsx` は**削除**し、上記2つに置き換える（中の各設定 UI・ロジック・既定値・ランダム化関数・`BREAK_DEFAULT_ROTATIONS` 等はそのまま移植）。SectionHeader の見出しはそれぞれ「お題の設定」(ProblemConfigPanel) / 「セッション設定」(SessionConfigPanel) とする。
- `ConfigPanel` を import している箇所（`Lobby.tsx` のみ想定）を更新。他に参照があれば合わせて更新。

## タブ再編（Lobby.tsx）

### ルーム タブ（After）
1. セッションを開始ボタン（既存）
2. **`SessionConfigPanel`**（交代間隔・詳細設定）← お題・設定タブから移動・新規分割
3. ルームコード / QR / 参加URL（既存）
4. パスフレーズカード（既存）
5. 交代通知カード（`NotifySettingsPanel`、既存・据え置き＝部屋/個人の通知設定）
6. 参加者一覧（`RosterPanel`、既存）

### お題 タブ（After、旧「お題・設定」）
1. **お題あり/なしトグル**（`ProblemModeToggle`）← ルームタブから移動・**タブ先頭**
2. **`ProblemConfigPanel`**（言語/難易度/言語プール）← 分割後
3. AI お題生成の解錠（`onAiUnlock`/`onProblemModeSet`、host 限定・既存・据え置き）
4. お題本体 / ProblemEditor（既存・据え置き）

### タブ定義
- ラベル: `["ルーム", "お題"]`（旧 `"お題・設定"` を `"お題"` に変更）。
- タブの ID/順序・選択状態管理（`Tabs` コンポーネント）はそのまま。

## 振る舞い・データフローの不変条件

- `SessionConfig` の形・`onChange` 契約・各ハンドラ（`onProblemModeSet`/`onAiUnlock` 等）は**不変**。
- お題なし（`problemEnabled=false`）時に ProblemConfigPanel が言語/難易度/プールを隠す挙動は維持。お題本体・AI解錠の表示条件も現行通り。
- 開始ボタンの活性条件（`disabled={!room.problem}` 等）は不変。お題あり/なしトグルがお題タブに移っても、開始判断（ルームタブ）はお題の用意状況に従う（既存ヘルプ文「お題は自動で用意されます。…『お題』でいつでも変更できます」の参照先タブ名を「お題」に更新）。
- host 限定表示（編集系は editor+ / host のみ）の権限ガードは現行通り。
