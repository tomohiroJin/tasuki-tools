# v2.2 Phase 3b: 任意ルームパスフレーズ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推奨）または superpowers:executing-plans。各ステップは TDD・`- [ ]` で追跡。

**Goal:** 主催者が任意でルームにパスフレーズを設定でき、設定時は room.join がコード＋一致するパスフレーズを要求する（未設定なら従来どおりコードのみ）。パスフレーズ平文はスナップショットに載せず、サーバ側 Map で保持する（v2.2 Epic 4 / R4-2）。

**Architecture:** パスフレーズ平文は handlers のインスタンス Map（`hostTokens` と同型・スナップショット非混入）で保持し、join 時に検証する。ルームの保護状態は平文を含まない boolean `passphraseProtected` を Room/snapshot に持たせ UI 表示に使う。host 専用コマンド `room.passphrase.set`（空文字＝解除）で設定。join 失敗は既存の join レート制限に積算してブルートフォースを緩和。後方互換（未設定＝従来どおり・既定オフ）。

**Tech Stack:** TypeScript, Valibot（境界検証）, neverthrow, React 18 + @testing-library, vitest。

**正本spec:** `docs/superpowers/specs/2026-06-10-v2.2-experience-lifecycle-security-design.md`（Epic 4 / R4-2・R4-4）

**作業ディレクトリ:** `tdd-mob-pro-timer/`。テスト: `~/.local/bin/pnpm --filter @tdd-mob/<pkg> exec vitest run <file>`（pkg=core/sync/web）。

## 設計の要点（前提知識）

- **平文の保持先**: handlers の `roomPassphrases = new Map<string, string>()`（code→平文）。`hostTokens`/`resumeTokens` と同じインスタンス Map で、**Room にも snapshot にも平文を載せない**（R4-2「トークン同様の扱い」）。`releaseRoom` でクリア。
- **保護状態の可視化**: Room に optional `passphraseProtected?: boolean`（平文ではなく「保護中か」の boolean）を持たせ、`RoomSchema` にも `v.optional(v.boolean())` を追加（既存 `problemMode` と同じ後方互換パターン）。host UI の「🔒 設定中」表示と「解除」操作に使う。handler が Map と boolean を同時更新する。
- **設定コマンド**: host 専用 `room.passphrase.set`（`{command, passphrase}`、`passphrase===""` で解除）。`role.set` と同じ専用 dispatch ＋ host チェック。`HOST_ONLY_COMMANDS` にも追加。
- **join 検証**: `handleRoomJoin` の**新規参加パス**（resume ブロックの後・新規 participant 作成の前）で、`roomPassphrases.get(code)` が存在すれば `cmd.passphrase` 一致を要求。不一致/未提供は失敗を `joinFailures` に積算（既存レート制限と統合）し `PASSPHRASE_REQUIRED`/`PASSPHRASE_MISMATCH` を返す。**resume（再接続）はパスフレーズ不要**（既に admit 済み＝resume ブロックが先に return する）。
- **join 画面 UX**: 任意のパスフレーズ入力欄を常設（未設定ルームでは空のまま参加可）。不一致時はエラー表示。
- **入力長**: `MAX_PASSPHRASE=128` を aggregate に追加し schema で `v.maxLength`（巨大入力 DoS 対策・既存の入力長方針と整合）。

(c) `handleRoleSet` の近くに `handleRoomPassphraseSet` を追加:
```ts
  /** ルームパスフレーズを設定/解除する（host 限定・R4-2）。空文字で解除。
   *  平文は roomPassphrases に保持し、Room には passphraseProtected(boolean)のみ反映。 */
  async function handleRoomPassphraseSet(
    connId: string,
    cmd: { command: "room.passphrase.set"; passphrase: string },
  ): Promise<Result<CreateResult, string>> {
    const room = findRoomByConnId(connId);
    if (!room) {
      broadcaster.sendTo(connId, { type: "error", code: "NOT_IN_ROOM", message: "ルームに参加していません" });
      return err("NOT_IN_ROOM");
    }
    const actor = room.participants.find((p) => p.connId === connId);
    if (!actor || actor.role !== "host") {
      broadcaster.sendTo(connId, { type: "error", code: "UNAUTHORIZED", message: "パスフレーズ設定はホストのみ実行できます" });
      return err("UNAUTHORIZED");
    }

    if (cmd.passphrase === "") {
      roomPassphrases.delete(room.code);
    } else {
      roomPassphrases.set(room.code, cmd.passphrase);
    }
    const updatedRoom: Room = { ...room, passphraseProtected: cmd.passphrase !== "" };
    store.put(updatedRoom);
    broadcaster.broadcastSnapshot(updatedRoom.code, updatedRoom);

    return ok({ code: updatedRoom.code, participantId: actor.participantId, hostToken: "", resumeToken: "" });
  }
```

(d) `HOST_ONLY_COMMANDS` に `"room.passphrase.set",` を追加。

(e) `releaseRoom` に追加:

  function releaseRoom(roomCode: string): void {
    hostTokens.delete(roomCode);
    roomPassphrases.delete(roomCode);
    for (const [token, info] of resumeTokens) {
      if (info.roomCode === roomCode) resumeTokens.delete(token);
    }
  }

`handleRoomJoin` の**新規参加パス**（resume ブロックの後・`// 新規参加者は editor として登録` のコメント直前）に追加:
```ts
    // パスフレーズ保護ルームは新規参加時に一致を要求する（R4-2）。
    // resume（再接続）は上の resume ブロックで return 済みのためここには来ない＝再認証不要。
    const requiredPassphrase = roomPassphrases.get(cmd.code);
    if (requiredPassphrase !== undefined && cmd.passphrase !== requiredPassphrase) {
      // 失敗をレート制限に積算（パスフレーズ総当たりの緩和・R4-2/既存 join 制限と統合）。
      joinFailures.set(connId, [...(joinFailures.get(connId) ?? []), now]);
      const code = cmd.passphrase ? "PASSPHRASE_MISMATCH" : "PASSPHRASE_REQUIRED";
      broadcaster.sendTo(connId, {
        type: "error",
        code,
        message: code === "PASSPHRASE_REQUIRED" ? "このルームはパスフレーズが必要です" : "パスフレーズが一致しません",
      });
      return err(code);
    }
```
注: `now` は `handleRoomJoin` 冒頭で `const now = clock.now();` 済み。`cmd.passphrase` は `RoomJoinCommand` の任意フィールド（Task 1）。

  return (

        </div>
      ) : (
        <div className="flex gap-2">
          <input
            type="password"
            value={value}
            onChange={(e) => setValue(e.target.value)}
            aria-label="パスフレーズ"
            maxLength={MAX_PASSPHRASE}
            placeholder="任意。設定すると参加に必要"

          />
          <PrimaryButton
            onClick={() => { if (value) { onSet(value); setValue(""); } }}
            className="px-4 py-2 text-sm"
          >
            設定
          </PrimaryButton>
        </div>
      )}
    </div>
  );
