## Constitution Check

憲法（[`docs/constitution.md`](../../constitution.md)）のコンプライアンスゲート。

| 原則 | 判定 | 根拠 |
|---|---|---|
| I. テスト駆動開発 | 通過 | 直す崩れごとに、先に測る E2E（か部品の単体テスト）を赤で書いてから直す |
| II. 技術選定は ADR を通す | 通過 | 余白の持ち主の約束とスクリーンショットの比較を入れるかは新しい ADR で決める（#553）。依存は足さない |
| III. 揮発インメモリと単純運用 | 該当なし | 同期サーバーの状態に触れない |
| IV. 境界の型安全 | 該当なし | 境界の検証に触れない |
| V. 実画面検証 | 通過 | 直した画面は 5 つの幅で撮って前後を比べる。測る検査は E2E のハーネス（実ビルド・本番と同じ Caddy）で流す |
| VI. 依存は内向き | 該当なし | ドメイン層に触れない |
| VII. 検査は壊して確かめる | 通過 | 足した検査ごとに、わざと崩して赤くなることを確かめ、変異を足す |
| VIII. 記録が正本 | 通過 | 決定は ADR、使い方は `packages/ui/README.md`、作法は DoD、各項目の扱いは一覧の補遺 |
| IX. 小さく回す | 通過 | 子 ISSUE ごとに PR 1 本。デプロイは伴わない（配るのは利用者の判断） |
| X. 抽象は実需で | 通過 | 部品は 2 画面以上が使うものだけ足す（ADR 0022 決定 2）。洗い出しで見出し＋操作の行は 4 通り・縦に積む並びは全アプリにある |
| XI. 秘密と個人情報を持ち込まない | 該当なし | 秘密・個人情報を扱わない |

**逸脱なし。** Complexity Tracking での正当化を要する項目はない。

## 分け方と順序

崩れの原因ごとに子 ISSUE に分ける。約束（#553）を先に決め、直しをそれに沿って行う。

| 段 | 子 ISSUE | 一覧の項目 | 変異 ID の帯（実際に使った帯は宣言の `RESERVED_*` が正本） |
|---|---|---|---|
| 1 | #553 余白の持ち主の約束（ADR）・並びの部品・poker の参加者の欄・Markdown の段落 | #1・#3・#6・#18・#33 | 宣言の `RESERVED_*` で「#553」を見る（1200〜1219・1250〜1259・1270〜1289・1340〜1349。最初の割り当て 1000〜1009 は他の ISSUE が先に使った） |
| 2（並行） | #554 共通の見出しと下端の帯 | #2・#5・#11・#12・#13・#19・#29 | 宣言の `RESERVED_*` で「#554」を見る（1220〜1229・1240〜1249・1260〜1269） |
| 2（並行） | #555 poker・landing・checkin の札の並び | #4・#8・#9・#10・#21・#22・#27・#28・#30 | 未定（宣言の `RESERVED_*` を見る） |
| 2（並行） | #556 timer・roulette・agenda・topic の行と並び | #7・#14〜#17・#20・#23〜#26・#31・#32 | 未定（宣言の `RESERVED_*` を見る） |
| 3 | #557 重なりと余白の E2E・DoD の作法・一覧の更新 | 全体 | 未定（宣言の `RESERVED_*` を見る） |
| 3 | #558 部品とトークンの見本 | — | 未定（宣言の `RESERVED_*` を見る） |

- 段 2 の 3 本は worktree を分けて並行する。触るファイルが重なるのは `apps/poker-web/src/index.css`（#554 の帯と #555 の札）と変異の宣言の末尾だけ。後から入る側が main を取り込んで両方残す
- 段 3 は段 2 が main に入ってから始める（検査は直した後の画面で緑になる必要がある）
- 各 PR は終わりを報告する前に、実装したのとは別のエージェントの敵対的レビュー（`docs/guides/procedures/adversarial-review.md`）と `/code-review <番号>` を通す

## 検証の時間の見積もり

| 検証 | 1 回の見込み | 回数の見込み |
|---|---|---|
| `pnpm check:fast`（型・lint・単体・監査・差分の変異） | 5〜15 分（変異の宣言に触れると全件に倒れるので `--id` で絞る） | PR ごとに 2〜3 回 |
| E2E（触った spec だけ） | 2〜5 分 | PR ごとに 3〜5 回 |
| E2E（全件） | 10〜15 分 | PR ごとに 1 回 |
| 変異（足した ID だけ・`--id`） | 5〜15 分 | PR ごとに 1〜2 回 |
| 撮影（5 つの幅・前後） | 3〜5 分 | PR ごとに 1〜2 回 |
| CI | 20〜30 分 | PR ごとに 1〜3 回 |

見込みの 2 倍を超えたら、補遺に理由を書く。
