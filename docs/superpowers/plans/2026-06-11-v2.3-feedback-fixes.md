## 設計の要点（前提知識）

- **`secondsLeft(clock, now)`**: `if (!clock.running) return clock.secondsLeftAtAnchor;` 稼働中は `secondsLeftAtAnchor − (now−anchorServerTime)`。つまり**停止中は `secondsLeftAtAnchor` がそのまま表示**される。
- **#2a の真因**: `evolveSessionPaused` は `accumulatedElapsedMs` を加算するが `secondsLeftAtAnchor` を更新しない → 停止中 `secondsLeftAtAnchor`(満タン) が出る。
- **#2b の真因**: `BreakStarted/BreakEnded` は evolve switch で `return agg`（no-op）。clock を止めない。
- **#3 の真因**: `SessionReset` → `initialAggregate(config)`（running=false）。phase は変えない → session 画面のまま停止して詰む。
- **member.move パターン**: `MemberMoved{fromIndex,toIndex,now}` → `decideMemberMove`（範囲検証）→ `evolveMemberMoved`（rotation/driverCounts splice＋currentIndex 追跡）。**shuffle はこの型を踏襲**。
- **records**: `apps/web/src/records/indexeddb.ts` に `loadRecords()`/`deleteRecord(id)`/`saveRecord()` が既存。読み出し画面が無いだけ。

```ts
function evolveSessionPaused(agg: Aggregate, now: number): Aggregate {
  const addedMs = agg.clock.runningSince !== null ? now - agg.clock.runningSince : 0;
  // 一時停止時点の残量を secondsLeftAtAnchor に凍結する（停止中 secondsLeft はこれを返すため）。
  const elapsedSinceAnchor = (now - agg.clock.anchorServerTime) / 1000;

    session: { ...agg.session, isPaused: true },
    clock: {
      ...agg.clock,
      running: false,
      secondsLeftAtAnchor: frozen,
      anchorServerTime: now,
      accumulatedElapsedMs: agg.clock.accumulatedElapsedMs + addedMs,
      runningSince: null,
    },
  };
}
```

```ts
function evolveBreakStarted(agg: Aggregate, now: number): Aggregate {
  const addedMs = agg.clock.runningSince !== null ? now - agg.clock.runningSince : 0;
  const elapsedSinceAnchor = (now - agg.clock.anchorServerTime) / 1000;
  const frozen = Math.max(0, agg.clock.secondsLeftAtAnchor - elapsedSinceAnchor);

    ...agg,
```

```ts
function evolveMembersShuffled(agg: Aggregate, order: number[]): Aggregate {
  const oldRotation = agg.session.rotation;
  const oldCounts = agg.session.driverCounts;
  const currentName = oldRotation[agg.session.currentIndex];
  const newRotation = order.map((i) => oldRotation[i]!);
  const newDriverCounts = order.map((i) => oldCounts[i] ?? 0);
  // 現ドライバーを現役に保つ（新配列での位置に remap）。
  const remapped = newRotation.indexOf(currentName ?? "");
  return {
    ...agg,
    session: { ...agg.session, rotation: newRotation, driverCounts: newDriverCounts, currentIndex: remapped >= 0 ? remapped : 0 },
  };
}
```
