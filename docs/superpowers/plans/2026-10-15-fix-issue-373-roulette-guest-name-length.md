# ルーレットのゲストの名前欄の上限と、長い名前の札の表示（#373）実装計画

**Goal:** (1) ルーレットのゲストの名前欄が 24 字で切れる欠陥を直し、上限を `@tasuki/room-core` の `MAX_DISPLAY_NAME`（40）から取る。(2) 40 字の名前が結果の札からはみ出して直下の一言・ボタンに重なる欠陥（実画面で発覚）を、札の中に収める。

**Architecture:** `GuestForm.tsx` の自前定数 `MAX_NAME_LENGTH = 24` を消し、`maxLength` に `MAX_DISPLAY_NAME` を渡す。landing の `CreateRoom` / `JoinRoom`、timer の `RosterPanel` と同じ扱い（`maxLength` だけ。正規化と検証はサーバーが持つ）にそろえる。

## 前提の実測

- `GuestForm.tsx` は `MAX_NAME_LENGTH = 24` を `maxLength` に渡している（Issue 本文どおり）。`MAX_DISPLAY_NAME = 40`（room-core）。
- 他のツールは `maxLength={MAX_DISPLAY_NAME}` のみ。貼り付けは `maxLength` がブラウザで切り、正規化は境界（サーバー）で行う。したがって「同じ扱い」とは `maxLength={MAX_DISPLAY_NAME}` である。

## 決めること

- 超過の扱い: 他と同じ `maxLength` に委ねる（推奨案）。クライアント側で正規化してから数える案は、他のツールに無い振る舞いを足すので採らない。
- 輪の上での省略はスコープ外。

## 札の修正（#373 の完了条件「40 字の輪と札の表示」）

- 原因: 札は縦横比が固定（8:5・幅 13〜16rem）なのに、名前は短い名前と同じ大きさ（約 38px）のままで折り返し、40 字で札の上下にはみ出した。
- 直し方: `apps/roulette-web/src/card-name-size.ts`（純粋関数）が名前の**表示幅**（全角 1・半角 0.6。円盤の席と同じ `isHalfWidth` を再利用）（書記素単位。`Intl.Segmenter`。共有の物差しは `wheel-geometry.ts` の `emWidthOf`）で 3 段（`lg` ≤6・`md` ≤20・`sm`）に分ける。`ResultCard` が `data-size` を付け、CSS が段ごとの字の大きさ（デザイン tokens）と名前の要素の最大行数（lg 2・md 3・sm 3）の省略を持つ。
- 決めたこと: 最小の段でも見出し「次の進行役」と「さん」（`--font-size-sm`）より小さくしない（xs の段は置かない）。`lg` は字の大きさが従来のまま（2 行の安全網だけ掛ける。上限 6 は、全角 7 字以上で名前が 2 行になり「さん」が次の行へ回ると札の枠に張り付くため）。省略は名前の要素（`.roulette-card-name-text`）だけで行い、「さん」は外に置いて切らない。全文は直下の一言と読み上げ（`role="status"`）が持つ。
- 検査: `tests/card-name-size.test.ts`（段の境目の表・英字名・書記素（ZWJ の絵文字・国旗・結合文字）・半角カナ・席の物差しとの共有）、`tests/result-card.test.tsx`（`data-size` と名前・「さん」の別要素・CSS の段ごとの font-size と line-clamp の対応・「さん」の nowrap）。

## 申し送り（この PR では変えない）

- 札の `md` の段（表示幅 6〜20）は、実画面で全パターンを測っていない。最悪でも 3 行で省略されるだけで、札からはみ出さない見込み（楽観を受け入れる）。
- 名前欄は NFKC 正規化の前の文字数で数える（`maxLength`）。正規化で字数が変わる名前（全角英数・合成済みの記号など）は、サーバーの検証（正規化後 40 字）と数え方がずれる。landing・timer の名前欄と同じ既知の扱いで、この PR では変えない。
- `maxLength` は UTF-16 の長さで数える。絵文字などサロゲートペアを含む名前は 40 字より少ない字数で打ち止めになる。landing の `CreateRoom` / `JoinRoom`・timer の `RosterPanel` にある既存の扱いで、EARS は「他のツールの名前欄と同じ扱い」なので揃えたまま変えない。
- 輪の上で長い名前をどう省略するか（円盤の席では 3〜4 字で切れる）はスコープ外のまま。
