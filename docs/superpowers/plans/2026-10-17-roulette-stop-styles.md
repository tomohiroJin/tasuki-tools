## Constitution Check

憲法（[`docs/constitution.md`](../../constitution.md) v2.1.4）のコンプライアンスゲート。

| 原則 | 判定 | 根拠 |
|---|---|---|
| I. テスト駆動開発 | 通過 | 止まり方の引き方・長さ・角度・画面の局面を、先に赤いテストで書く。乱数は注入する（S3・S8） |
| II. 技術選定は ADR を通す | 該当なし | 新しい依存・技術を足さない。決定は ADR 0026 への追記に留める |
| III. 揮発インメモリと単純運用 | 通過 | 止まり方は回転の一部としてルームの揮発メモリに置く |
| IV. 境界の型安全 | 通過 | コマンドは足さない。フレームの新しい項目は省略可の文字列（非 strict・S7） |
| V. 実画面検証 | 通過 | 乱数源を手元で差し替え、2 つの画面で 8 種を回して確かめる。モックで見え方を見比べられる |
| VI. 依存は内向き | 通過 | `roulette-core` は乱数を引数で受ける。角度は画面が描く |
| VII. 検査は壊して確かめる | 通過 | 変異 370〜379 を足し、1 本ずつ当てて赤を見る。行のずれた既存の変異は当て直す |
| VIII. 記録が正本 | 通過 | 決定は ADR 0026 の追記、設計と経緯は設計正本 |
| IX. 小さく回す | 通過 | PR は 1 本で、コミットを core・同期サーバー・画面・変異・文書で分ける |
| X. 抽象は実需で | 通過 | 確率の調整・止まり方を選ぶ機能は作らない（S3）。止まり方は区間の列の表 1 つで書く |
| XI. 秘密と個人情報を持ち込まない | 通過 | 新しいログを足さない |

**逸脱なし。** Complexity Tracking での正当化を要する項目はない。

## 0. 取り決め

- spec §3 は利用者の「推奨で進めてよい」を受けて推奨のまま決めた
- **ほかの決め方の回帰を守る**: 既存のテストの期待値を変えない。止まり方の引数を省くと #401 の表のまま
- 変異の ID は **370〜379**（#420。360〜369 は #93 の帯）

## 1. タスク

1. **core**: 止まり方の表（名前・延び）・`drawStopStyle`・`pickStopsMs`／`spinDurationMs` の止まり方の引数・回転への載せ方（押して止めるは除く）・スキーマ
2. **同期サーバー**: 回すときに同じ乱数源から止まり方を引く
3. **画面**: 止まり方の角度（区間の列）・1 人目の回転への掛け方・止まる時刻の表へ止まり方を渡す（局面・何人目まで・描き直しの時刻）
4. **モック・実画面・E2E・変異・文書**（ADR 0026 の追記・NOTES の配る窓・振り返り）
