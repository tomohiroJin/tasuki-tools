# S0（#50 先行 CI）+ S1（#16 骨格化）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tasuki の 2 つの独立した monorepo を単一の pnpm workspace + turbo に束ね、公開されている timer の挙動を一切変えずに、ルートで全ツールを 1 コマンド検証できる状態にする。

**Architecture:** 3 つの PR に分ける。**S0** はルートに CI を置いて main を保護する（現構成のまま）。**S1-a** はディレクトリ移動・ワークスペース統合・パッケージリネームを行うが、**型の厳しさと依存バージョンは一切変えない**（純粋な構造変更）。**S1-b** は tsconfig の統合と React 19 化を行う（型と依存の変更のみ、構造は動かさない）。この分離により、退行が出たとき「移動が原因か、型/依存が原因か」を切り分けられる。

**Tech Stack:** pnpm workspace / turbo 2.x / TypeScript 5.8 / React 19 / Vite 6 / Vitest 3 / Bun（sync サーバー）/ ESLint 10 flat config / GitHub Actions / Caddy + systemd（本番）

**設計の正本:** `docs/superpowers/specs/2026-08-04-monorepo-unification-design.md`

## Global Constraints

- **公開挙動は不変**: 本番 `https://tasuki.niku9.click/` の timer は URL・機能とも変わらない。`/poker` は**元々未公開**（timer の SPA フォールバックが返っているだけ）なので、守るべきは `/` の timer のみ
- **バージョンは新しい方へ統一**: pnpm `11.5.0` / turbo `^2.5.4` / TypeScript `^5.8.3` / React `^19.1.0`
- **Node は 22 系が必須**: pnpm 11.5.0 は **Node.js >= 22.13** を要求する（`node:sqlite` を使うため。Node 20 では `ERR_UNKNOWN_BUILTIN_MODULE` で起動すらしない）。ルート `package.json` の `engines.node` は **`>=22.13.0`**、CI の `node-version` は **22**。timer の旧宣言 `>=20.0.0` をそのまま持ち込んではいけない（実測: devcontainer は v22.23.2 で動くため、ローカルだけでは気づけない。Task 1 の初回 CI 実行で露見した）
- **npm スコープは `@tasuki/`**、パッケージ名は `<tool>-<layer>` 形式（`timer-core` `poker-sync` 等）、ディレクトリ名はパッケージ名と一致させる
- **ディレクトリ移動は必ず `git mv`** を使う（履歴を保つ）
- **`main` への直接コミット禁止**。各段でブランチを切る
- **コミットメッセージは Conventional Commits + 日本語**（`.claude/rules/git-workflow.md`）
- **S1-a では型の厳しさを変えない**。`exactOptionalPropertyTypes` / `verbatimModuleSyntax` は poker のパッケージ側に残し、base へ昇格させない
- **S1-a では依存バージョンを変えない**。React 18/19 併存のまま
- **本番デプロイは利用者のいない時間帯に行う**（再起動でルームが全消滅する揮発インメモリ設計）

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

# corepack が pnpm を取得するとき、非対話環境で確認プロンプトを出さない
env:
  COREPACK_ENABLE_DOWNLOAD_PROMPT: "0"

jobs:
  timer:
    name: tdd-mob-pro-timer
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: tdd-mob-pro-timer
    steps:
      - uses: actions/checkout@v4

      # pnpm の版は各ディレクトリの package.json の packageManager 宣言に従わせる。
      # pnpm/action-setup で版を固定すると、timer(9.15.0) と poker(11.5.0) の
      # 食い違いをどちらかに寄せることになり、ローカルと CI で挙動が変わる。
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: corepack enable

      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test
      - run: pnpm build

  poker:
    name: planning-poker
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: planning-poker
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: corepack enable

      - run: pnpm install --frozen-lockfile
      # poker には lint / test:unit が無い（S1-b で lint を追加する）
      - run: pnpm typecheck
      - run: pnpm test
      - run: pnpm build
```
