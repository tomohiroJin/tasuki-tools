# v2.2 Phase 2b: ホスト管理（明示的移譲＋委譲可視化） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推奨）または superpowers:executing-plans。各ステップは TDD・`- [ ]` で追跡。

**Goal:** 主催者が任意のオンライン参加者へホストを明示的に手動移譲でき、移譲・自動委譲のいずれでも「誰がホストか」が常時わかり、変更が画面通知される（v2.2 Epic 2 / R2-3・R2-4・R2-5）。

**Architecture:** ホスト交代＝「対象を host、現 host を editor、`hostParticipantId` を付け替え」の純粋変換 `transferHost`（core）に一本化し、明示移譲（handlers の新コマンド `host.transfer`）と自動委譲（presence の不在委譲）の両方が使う。移譲はどちらも snapshot で `hostParticipantId` を更新するため、**通知は新 signal を足さず「snapshot 差分監視」**で実現（web が `hostParticipantId` 変化を検知し既存 `banner` で告知）。現ホスト表示は既存 roster の「主催者」バッジを活用。R2-5（奪還/co-host）は非対象＝実装なし。

**Tech Stack:** TypeScript, Valibot（コマンド境界）, neverthrow, React 18 + @testing-library, vitest。

**正本spec:** `docs/superpowers/specs/2026-06-10-v2.2-experience-lifecycle-security-design.md`（Epic 2 / R2-3・R2-4・R2-5）

**作業ディレクトリ:** `tdd-mob-pro-timer/`。テスト: `~/.local/bin/pnpm --filter @tdd-mob/<pkg> exec vitest run <file>`（pkg = core/sync/web）。

## 設計の要点（前提知識）

- **既存のロール権威**: 認可は `authorize(role, command, hostParticipantId, participantId)`（role と hostParticipantId ベース。hostToken は無関係）。presence の自動委譲も「role と hostParticipantId の付け替え」だけで成立しており、hostToken は触らない。明示移譲も同じく role/hostParticipantId のみ付け替える。
- **`role.set` は専用 dispatch**（handlers `case "role.set"` → `handleRoleSet`）で、host 限定・**現 host 自身は対象不可**（「委譲は別経路」と明記）。`host.transfer` はこの別経路として並置する。
- **通知**: 既存 web の `banner`（`setBanner({text, kind})`・aria-live・自動消去）と、snapshot に常に載る `hostParticipantId` を使い、`useSwitchAlert` と同型の「直前値と比較して変化時だけ告知」で明示移譲・自動委譲の双方を1経路で拾う。**core/sync に signal 追加は不要。**
- **現ホスト可視化**: RosterPanel は既に `p.role === "host"` で「主催者」バッジを表示済み（Lobby/Session 双方で roster 使用）。追加の常時表示実装は不要（確認のみ）。
- **移譲先の制約**: オフライン参加者に渡すとルームが宙に浮くため、**対象はオンライン かつ 自分以外**に限定（spec「任意の参加者」をオンライン内で解釈）。

/** ホストを newHostParticipantId へ移譲する純粋変換（R2-3/R2-4）。
 *  対象を host、現 host を editor に付け替え、hostParticipantId を更新する。
 *  対象の存在・オンライン等の検証は呼び出し側（handler）が行う。 */
export function transferHost(room: Room, newHostParticipantId: string): Room {
  return {
    ...room,
    hostParticipantId: newHostParticipantId,
    participants: room.participants.map((p) =>
      p.participantId === newHostParticipantId
        ? { ...p, role: "host" }
        : p.participantId === room.hostParticipantId
          ? { ...p, role: "editor" }
          : p,
    ),
  };
}
```

  /** ホストを明示的に他のオンライン参加者へ移譲する（host 限定・R2-3）。
   *  自動委譲（presence）と同じ transferHost を用い、snapshot で全員に反映する。 */
  async function handleHostTransfer(
    connId: string,
    cmd: { command: "host.transfer"; participantId: string },
  ): Promise<Result<CreateResult, string>> {
    const room = findRoomByConnId(connId);
    if (!room) {
      broadcaster.sendTo(connId, { type: "error", code: "NOT_IN_ROOM", message: "ルームに参加していません" });
      return err("NOT_IN_ROOM");
    }
    const actor = room.participants.find((p) => p.connId === connId);
    if (!actor || actor.role !== "host") {
      broadcaster.sendTo(connId, { type: "error", code: "UNAUTHORIZED", message: "host.transfer はホストのみ実行できます" });
      return err("UNAUTHORIZED");
    }
    if (cmd.participantId === room.hostParticipantId) {
      broadcaster.sendTo(connId, { type: "error", code: "CANNOT_CHANGE_HOST", message: "自分自身へは移譲できません" });
      return err("CANNOT_CHANGE_HOST");
    }
    const target = room.participants.find((p) => p.participantId === cmd.participantId);
    if (!target) {
      broadcaster.sendTo(connId, { type: "error", code: "PARTICIPANT_NOT_FOUND", message: "対象の参加者が見つかりません" });
      return err("PARTICIPANT_NOT_FOUND");
    }
    if (target.presence === "offline") {
      broadcaster.sendTo(connId, { type: "error", code: "PARTICIPANT_OFFLINE", message: "オフラインの参加者へは移譲できません" });
      return err("PARTICIPANT_OFFLINE");
    }

    const updatedRoom = transferHost(room, cmd.participantId);
    store.put(updatedRoom);
    broadcaster.broadcastSnapshot(updatedRoom.code, updatedRoom);

    return ok({ code: updatedRoom.code, participantId: actor.participantId, hostToken: "", resumeToken: "" });
  }
```

```ts
/**
 * ホスト交代の通知メッセージを算出する純粋関数（R2-4）。
 *
 * snapshot に常に載る hostParticipantId の「直前値→現在値」の変化を見て、
 * 明示移譲・自動委譲の双方を 1 経路で検知する（新 signal は使わない）。
 * 初回（prev 未定義）や変化なしは null（＝通知しない）。
 */
import type { Room } from "@tdd-mob/core";

export function hostChangeMessage(
  prevHostId: string | undefined,
  room: Room,
  myParticipantId: string,
): string | null {
  const current = room.hostParticipantId;
  if (prevHostId === undefined || prevHostId === current) return null;
  if (current === myParticipantId) return "あなたがホストになりました。";
  const name = room.participants.find((p) => p.participantId === current)?.displayName ?? "";
  return `ホストが ${name} さんに移りました。`;
}
```

// ホスト交代（明示移譲/自動委譲の双方）を snapshot 差分で検知し、既存 banner で告知する（R2-4）。
useEffect(() => {
  if (!room) {
    prevHostRef.current = undefined;
    return;
  }
  const msg = hostChangeMessage(prevHostRef.current, room, participantId);
  prevHostRef.current = room.hostParticipantId;
  if (msg) {
    setBanner({ text: msg, kind: "warn" });
    if (bannerTimerRef.current) clearTimeout(bannerTimerRef.current);
    bannerTimerRef.current = setTimeout(() => setBanner(null), 4000);
  }
}, [room, participantId]);
