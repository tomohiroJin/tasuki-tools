# ADR-0036: 下端に留める帯は 40rem 未満で 2 列の格子に並べる

- **ステータス**: Accepted（2026-11-09。利用者が PR tomohiroJin/tasuki-tools#559 で採択。`docs/adr/0030` 決定 1 のとおり人が判断した）
- **関連**: #554（親 #479）・[ADR-0025](./0025-responsive-layout.md)（決定 5 の帯の部分をこの ADR が置き換える）・[ADR-0022](./0022-ui-components-layer.md)（部品層）・`packages/ui/README.md` の「帯の約束」

## 背景

ADR-0025 決定 5 は「操作の並びは `.ui-actions` で組み、狭い幅では縦に積む」と決めた。下端に留める帯（`.ui-actions--dock`）も同じく縦に積んでいたため、#479 の洗い出し（2026-11-06）で次が見つかった。

- poker の公開後（320・390px）で、3 つの操作が 3 段になり帯が約 200px になって、初期表示で結果の数字を隠した（#12）
- timer のセッション（320・390px）で、3 段の帯（約 180px）が盤の下半分を覆った（#19）
- agenda の手元の帯は、地が透明へ溶けて、後ろの進行表の字が帯の字に重なって読めた（#2）

## 決定

1. **40rem 未満の `.ui-actions--dock` は、縦に積まず 2 列の格子に並べる。** 操作は 2 段まで（4 つまで。5 つ以上は副の操作を帯の外へ出す）。
2. **目に見える操作**（`hidden`・`.ui-visually-hidden`・選択欄・`.ui-actions-start` の包みを除く）**の奇数の最後（主）は全幅の 1 段にする。** 4 つなら 2×2 で、主は最後（右下）の半分の幅になる。
3. **選択欄は先頭に置いて 1 段を使い、あれば続く操作は 2 つまで。**
4. **帯の字の後ろの地は不透明にする**（`--dock-ground`）。上端に内側の余白を置く。帯が覆う中身は、最下部までスクロールすると帯の上に出る。Tab で送った先が帯の後ろに隠れない余白（`--dock-max-height`）を、帯のある画面に掛ける。
5. 帯でない `.ui-actions` は、ADR-0025 決定 5 のまま、40rem 未満で縦に積む。

## 影響

- 部品の帯（`.ui-actions--dock`）を使う画面（poker・topic・roulette・timer）は、並びのクラスを変えずに 2 段に収まる。agenda の手元の帯・映す表示の帯・checkin の `.round-dock` は部品の帯を使わない（agenda の 2 つは地と線のトークンだけを共有する。checkin は独自の帯のまま）
- 帯の高さは、画面側が実際の高さを測って CSS 変数へ書く（agenda の手元の帯・映す表示の帯は ResizeObserver）。CSS の値は JS が動く前の既定値。部品の帯の逃がし余白（`--dock-max-height`）は実測（poker と timer）から決めた値で、文字の拡大は agenda の帯だけ E2E で測っている
- 招待の URL は省略せず、折り返して全部見せる（クリップボードが使えない端末では目で読むしかない）。招待の行は固定の境目を置かず、中身の幅で折り返す。1 行に収まるかは URL の長さによる（35 字で 864px 前後、本番に近い 39 字で 934px 前後、ASCII 90 字で 1374px 前後、日本語 74 字は 1440px でも収まらない）。それより狭い幅は見出しの段数を main 以下に保つため URL が行の中で折り返す（#5 の「768px で 2 行」の扱い）。URL の基準の幅は、段数が main 以下で URL の 1 行が 16 字以上になる範囲の中ほどに置く（物差しは px でなく段数）。`@container (width < 30rem)` は段数の境目ではなく、狭い欄での積み方の切り替え。コピーの結果はボタンの字を変えず、浮かぶ知らせで出す（字が変わると幅が変わって見出しの段数が変わるため）
- この ADR を採択するときは、ADR-0025 決定 5 の帯の部分をこの ADR が置き換える旨を、ADR-0025 の追記に反映する。採択は人が行う（`docs/adr/0030` 決定 1）
