# v2.2 Phase 3a: 運用可視化（管理エンドポイント＋回収ログ） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推奨）または superpowers:executing-plans。各ステップは TDD・`- [ ]` で追跡。

**Goal:** 運用者が「空ルームが正しく回収されているか」を確認できるよう、ADMIN_TOKEN 保護の read-only 管理エンドポイント（`/status`・`/admin/rooms`）と RoomReclaimer の構造化ログ＋累計回収数を追加する（v2.2 Epic 3 / R3-1〜R3-4 ＋ R4-1）。

**Architecture:** sync の WS アダプタを「`ws` が内部 HTTP を所有する `WebSocketServer({port})`」から「明示的 `http.createServer` ＋ `WebSocketServer({ server })`」へ切り替え、非 Upgrade の HTTP リクエストに `httpHandler` フックを通す。管理ルーティング＋トークン認証＋レポート生成は純粋関数（`admin.ts`）に分離してテスト可能にする。sync は 127.0.0.1 限定バインドのため管理面は元々インターネット非到達で、ADMIN_TOKEN は多層防御。core/web は不変（sync 限定）。

**Tech Stack:** TypeScript, Node `http`, `ws`, neverthrow, vitest。

**正本spec:** `docs/superpowers/specs/2026-06-10-v2.2-experience-lifecycle-security-design.md`（Epic 3 / R3-1〜R3-4・R4-1）

**作業ディレクトリ:** `tdd-mob-pro-timer/`。sync テスト: `~/.local/bin/pnpm --filter @tdd-mob/sync exec vitest run <file>`。

## 設計の要点（前提知識）

- **現状の HTTP**: `WsAdapter` は `new WebSocketServer({ port, host })` を使い、`ws` が内部 HTTP サーバを所有。非 WS の HTTP リクエストには `ws` 既定の **426 Upgrade Required** が返る（`/` で確認済み）。カスタム HTTP ルートは無い。
- **管理面の到達性**: sync は `HOST=127.0.0.1` でバインドし、Caddy は `/ws` のみ reverse_proxy する。よって `/status`・`/admin/rooms` は **VPS ホストからのみ到達**（インターネット非公開）。運用者は SSH 後に `curl -H "x-admin-token: $TOKEN" http://127.0.0.1:8787/status` で参照する。ADMIN_TOKEN は多層防御。
- **ADMIN_TOKEN 未設定時**: 管理ルートは「存在しない」扱い（非ルート＝426 に落とす）。設定時のみ有効化し、トークン不一致は 401（R3-3）。
- **回収可視化**: `RoomReclaimer` に累計回収数 `reclaimedCount` と、回収時のアイドル ms を `onReclaim(code, idleMs)` で渡し、server.ts が構造化ログを出す（journalctl で追える・R3-1）。
- **「最終活動時刻」の扱い**: Room には専用の lastActivity フィールドが無い。新フィールド追加は侵襲的なので本 Phase では追加せず、回収判定の実シグナルである **online 参加者数**（0 なら回収候補）と `createdAt` をレポートに含める（R3-2 の運用目的＝「空ルームが回収されているか」を満たす）。lastActivity の厳密追跡は対象外。

```ts
/**
 * 運用者向け管理エンドポイント（/status・/admin/rooms）の純粋ロジック（R3-2/R3-3/R4-1）。
 * ルーティング・トークン認証・レポート生成を http から切り離してテスト可能にする。
 * sync は 127.0.0.1 限定バインドのため管理面は元々非公開。ADMIN_TOKEN は多層防御。
 */
import type { Room } from "@tdd-mob/core";

export interface AdminRoomSummary {
  code: string;
  participants: number;
  online: number;
  hasDriver: boolean;
  createdAt: number;
}
export interface AdminReport {
  activeRooms: number;
  totalReclaimed: number;
  rooms: AdminRoomSummary[];
}

/** 現在のルーム一覧と累計回収数から運用レポートを組み立てる（純粋）。 */
export function buildAdminReport(rooms: Room[], reclaimedCount: number): AdminReport {
  return {
    activeRooms: rooms.length,
    totalReclaimed: reclaimedCount,
    rooms: rooms.map((r) => ({
      code: r.code,
      participants: r.participants.length,
      online: r.participants.filter((p) => p.presence === "online").length,
      hasDriver: r.session.rotation.length > 0,
      createdAt: r.createdAt,
    })),
  };
}

export interface AdminHttpDeps {
  adminToken: string | undefined;
  getReport: () => AdminReport;
}
export interface AdminHttpResult {
  status: number;
  contentType: string;
  body: string;
}

/**
 * 管理 HTTP リクエストを処理する（純粋）。管理ルートでなければ null（呼び出し側が 426 等に落とす）。
 * - ADMIN_TOKEN 未設定: 管理ルートでも null（存在を隠す）。
 * - GET 以外: null。
 * - トークン無し/不一致: 401。
 * - /status: 要約のみ。/admin/rooms: rooms 配列を含む。
 */
export function handleAdminHttp(
  method: string | undefined,
  url: string | undefined,
  headers: Record<string, string | string[] | undefined>,
  deps: AdminHttpDeps,
): AdminHttpResult | null {
  const path = (url ?? "").split("?")[0];
  if (path !== "/status" && path !== "/admin/rooms") return null;
  if (!deps.adminToken) return null; // 未設定なら存在を隠す
  if (method !== "GET") return null;

  const raw = headers["x-admin-token"];
  const provided = Array.isArray(raw) ? raw[0] : raw;
  if (provided !== deps.adminToken) {
    return { status: 401, contentType: "application/json", body: JSON.stringify({ error: "unauthorized" }) };
  }

  const report = deps.getReport();
  const body = path === "/status"
    ? { activeRooms: report.activeRooms, totalReclaimed: report.totalReclaimed }
    : report;
  return { status: 200, contentType: "application/json", body: JSON.stringify(body) };
}
```

> トークン比較は単純等価。本エンドポイントは 127.0.0.1 限定でインターネット非到達のためタイミング攻撃面は実質無し（許容）。

  private handleHttp(req: IncomingMessage, res: ServerResponse): void {

      return;
