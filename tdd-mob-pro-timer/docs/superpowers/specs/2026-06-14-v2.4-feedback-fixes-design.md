# v2.4 フィードバック対応 設計

- 作成日: 2026-06-14
- 対象: 実機フィードバック5点（AI お題の日本語化・言語/難易度の個別ランダム・言語プール絞り込み・参加者欄の縦圧縮・モブ順表示）
- 関連: [AI お題生成 設計](2026-06-12-ai-problem-generation-design.md) / [状態可視化 設計](2026-06-14-ai-status-visibility-design.md) / [品質実験](../../experiments/2026-06-14-ai-problem-quality-sonnet-vs-haiku.md)

## 目的

実機利用のフィードバック5点を解消する。

1. AI 生成お題の内容が英語で分かりにくい → **説明文を日本語化**。
2. 言語と難易度のランダムが同時にしか振れない → **別々に振れる**ように。
3. 言語ランダムが全10言語対象で使わない言語も出る → **使う言語を絞り込んだプールから**ランダム。
4. セッション開始後の参加者欄が縦に長く、多人数でスクロールが辛い → **縦を圧縮**。
5. 参加者の並びがモブ順と無関係で「今誰の番か」が追いにくい → **モブ順に並べ「今」を明示**。

## アーキテクチャ方針

- **WS プロトコル・sync・core 集約（aggregate/decide/evolve）は不変**。
- 変更は **core のプロンプト生成関数1つ**（項目1）と **web 表示層**（項目2〜5）のみ。
- 言語プール（項目3）は **ホストローカルの UI 設定**として `local-prefs` に永続し、`SessionConfig` には載せない（選ばれた言語だけが `config.set` で同期される）。

## 項目1: AI お題の内容を日本語化

**対象**: `packages/core/src/problem.ts` の `buildProblemPrompt(language, difficulty)`。

**変更内容**: プロンプトを以下の方針に変更する。
- `title` / `description` / `requirements` / `hints` は **自然で明確な日本語**で生成する。
- `exampleTest` は **`${language}` の正しい構文＋英語の識別子**（関数名・変数名は英語）。コード内コメントは日本語でもよい。
- それ以外の生成ルール（4〜6 要件・テスト可能性・難易度の目安・JSON のみ返す）は維持する。

**非変更**: `ProblemSchema`（文字列のまま・日本語可）、定型バンク（既に日本語）、検証ロジック `validateProblem`。

**受け入れ基準**:
- `buildProblemPrompt` の返す文字列が、説明文系を日本語で書くよう明示する指示を含む。
- `exampleTest` は英語識別子のコードである旨を指示する。
- 実生成（sonnet/haiku 各1件以上）で title/description/requirements/hints が日本語、exampleTest がコードになる。

---

## 項目2: 言語・難易度を別々にランダム

**対象**: `apps/web/src/ui/components/ConfigPanel.tsx`。

**変更内容**:
- 見出し右の「ランダム」ボタン（言語＋難易度を**同時**に振る `randomize`）を**廃止**する。
- 言語フィールドのラベル横に **言語専用のサイコロ🎲ボタン**、難易度フィールドのラベル横に **難易度専用の🎲ボタン**を置く。
- 言語🎲は**プール（項目3）から一様ランダム**で1つ選び `onChange({ language })`。
- 難易度🎲は3難易度（easy/medium/hard）から一様ランダムで1つ選び `onChange({ difficulty })`。
- 現在値と同じ値を引いても良い（毎回必ず変わる保証は不要）。

**受け入れ基準**:
- 言語🎲を押すと言語のみ変わり難易度は不変。難易度🎲を押すと難易度のみ変わり言語は不変。
- `canEdit=false`（観覧者）では🎲を表示しない。

## 項目3: 言語ランダムを絞り込みプールから

**対象**: `apps/web/src/ui/components/ConfigPanel.tsx`、`apps/web/src/prefs/local-prefs.ts`。

**変更内容**:
- ConfigPanel に「**ランダム対象の言語**」のチップ複数選択 UI を追加（10言語をトグル）。場所は言語🎲の近く、コンパクトな折りたたみ（`<details>`）で既定は閉じる。
- 選択状態を `local-prefs` に **`randomLanguagePool: string[]`** として永続（ホストローカル・`loadPreferences`/`savePreferences` の既存作法に追加）。
- **既定プール**: `["TypeScript", "JavaScript", "Python", "Go", "Java"]`（常用5言語）。
- 言語🎲はこのプールから一様ランダム。**プールが空のときは現在の言語を維持**（変更しない）。
- プール選択は **`SessionConfig` に載せない**。選ばれた言語だけが `config.set` で同期される。

**設計判断**: プールはホスト個人の利便設定でありセッション横断で再利用したいため、同期状態（Room）ではなくローカル永続にする。これにより core/sync は不変。

**受け入れ基準**:
- チップで言語を ON/OFF でき、リロード後も選択が残る（localStorage 永続）。
- 言語🎲はチェックされた言語のみから選ぶ。
- プールを全 OFF にして🎲を押しても言語は変わらない（クラッシュしない）。
- 既定では常用5言語が ON。

## 項目4: 参加者欄を縦に圧縮（2段＋高さ上限スクロール）

**対象**: `apps/web/src/ui/components/RosterPanel.tsx`、呼び出し側 `apps/web/src/ui/Session.tsx`。

**変更内容**:
- 1人あたりの行を **3段→2段**に圧縮する。
  - **1段目**: 順番番号（項目5）＋在席ドット＋名前＋「▶ 今」マーカー＋主要バッジ（主催者/観覧/代理/離脱中）を**横並び**（`flex-wrap`、名前は省略せず折返し可）。
  - **2段目**: 操作ボタン（改名/一時離脱/順番↑↓/譲る/外す）をコンパクトに右寄せ（既存 MiniButton を流用）。
  - 改名中（`isEditing`）の専有レイアウトは現状維持。
- 参加者リスト `<ul>` に **高さ上限＋内部スクロール**を付ける（約4〜5人分の高さ＝`max-h-[20rem] overflow-y-auto`）。
- 高さ上限は **`scrollable?: boolean` prop で制御**（true のとき上記 max-height クラスを `<ul>` に付与・既定 false）し、**Session でのみ `scrollable` を渡す**。Lobby/Solo の RosterPanel 使用箇所は prop を渡さず従来通り（高さ無制限）。

**受け入れ基準**:
- 1人の表示が2段になり、3段時より縦が縮む。
- Session で参加者が多いとき、リストが指定高さで内部スクロールし、画面全体のスクロールが短くなる。
- Lobby/Solo の表示は回帰しない（高さ上限が付かない）。
- 操作（改名/順番/譲る/外す/一時離脱）は引き続き機能する。

## 項目5: モブ順表示と「今誰？」

**対象**: `apps/web/src/ui/components/RosterPanel.tsx`。

**変更内容**:
- 描画前に参加者を **rotation 順に並べ替える**。
  - rotation 内の参加者: `rotation.indexOf(displayName)` 昇順。
  - rotation 外（観覧者・rotation に含まれない者）: **末尾**にまとめる（元の相対順を維持＝安定ソート）。
- rotation 内の各行に **順番番号バッジ**（1 始まりの整数。`rotationIndex + 1` を表示）を付ける。
- **現ドライバー**を強調（既存の赤背景＋枠）＋「▶ 今」テキスト（既存「▶ 現在」を「▶ 今」に統一、色＋テキスト併記を維持）。
- `rotation` が未指定/空のときは**従来の配列順**（番号なし）にフォールバック。

**設計判断**: 並べ替えは**表示のみ**。`onMove(fromIndex, toIndex)` は引き続き `rotationIndex` を使うため、ソートしても順番入れ替え操作は正しく動く。`currentDriverName` 判定（名前一致）も不変。

**受け入れ基準**:
- 参加者がモブ順（rotation 順）に並ぶ。
- 各ドライバー行に順番番号が出る。
- 現ドライバーが視覚的に明確（色＋「▶ 今」）。
- 観覧者・rotation 外は末尾。
- ホストの順番↑↓入れ替えが従来通り機能する（並べ替え後も正しい index で動く）。

## テスト方針

| 層 | 対象 | 検証 |
|---|---|---|
| core | `buildProblemPrompt` | 日本語指示・英語コード指示を含む（純関数の単体テスト） |
| web | `local-prefs` | `randomLanguagePool` の保存/読込・既定値 |
| web | ConfigPanel | 言語🎲はプールから/難易度🎲は難易度から・個別に振れる・観覧者は非表示・プール空で言語🎲は無変化 |
| web | RosterPanel | rotation 順ソート・順番番号・現ドライバー強調・観覧者末尾・2段レイアウト・scrollable prop で max-height 付与 |
| 結合 | 全体 | typecheck / web test / build 緑 |
| 実機 | playwright | 5点を目視確認。項目1は実生成（sonnet/haiku）で日本語出力を確認 |

## 非対象（YAGNI）

- Lobby の独自参加者一覧へのモブ順表示適用（フィードバックは「セッション開始後」が対象）。
- 言語プールのサーバー同期（ホストローカルで十分）。
- exampleTest のコメント/識別子の日本語化（コードとして不自然になるため）。
- 参加者欄の操作ボタンの「…」展開（2段＋スクロールで縦圧縮の目的を達成するため、追加の折りたたみは入れない）。
